## Description

## What is the Problem Being Solved?

We do not currently support the `"imports"` directive in a package.json, which translate import specifiers with a leading `#` to aliases, possibly depending on conditions.

## Description of the Design

Possibly in the process of completing #2897, we need to translate imports into patterns or module aliases internal to a package. Much of the same machinery exists for `"exports"` and will need to change for patterns. We also may need to adjust the logic for resolving Node.js-style import specifiers to take into account the `#` prefix.
