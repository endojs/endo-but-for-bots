As I mentioned on Slack, I believe EventEmitter instances like many Node.js objects are fundamentally incompatible with being hardened (use expando properties for internal state). We may be able to patch some things, but in the meantime @kriskowal suggested we add a "cannot freeze" proxy as an expando property to the prototype of such objects so that we fail loudly instead.
