## What is the Problem Being Solved?

In #1894, we deleted the bundler integration tests, which had become too stale to represent modern bundlers or to be readily updated in place. SES should not be bundled with a third-party bundler, but can be bundled safely with Endo’s own bundler. We should have

1. a browser integration test that verifies that SES can lockdown with the bundle generated by Endo, and also
2. verify that the SES code that detects that it had been bundled improperly aborts lockdown under those circumstances. For example, if async functions have been translated down to generator functions.
