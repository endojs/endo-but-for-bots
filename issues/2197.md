## Description

## What is the Problem Being Solved?

We frequently have a need to measure the performance of JavaScript snippets and code blocks in V8 or XS, and sometimes in both. This can serve purposes as simple as comparing alternative implementations of a function (e.g., [`str.replace(/^#/, "")` vs. `str.startsWith("#") ? str.slice(1) : str`](https://github.com/endojs/endo/pull/1804#discussion_r1346236499)), [diagnosing time complexity issues](https://github.com/endojs/endo/pull/2001), and even analyzing behavior of agoric-sdk contracts and vats.

## Description of the Design

Create an `esbench` tool that wraps [`eshost`](https://github.com/bterlson/eshost) for testing across ECMAScript implementations.
