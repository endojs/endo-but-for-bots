## Description

This isn't strictly an endo problem, but it has caught me a couple times, so I thought it was worth "not squandering my ignorance" (thanks @michaelfig  :) ).

Several endo modules, like capTP require lockdown to happen before their import, but since imports are all hoisted, this means the lockdown call MUST happen in an imported file, and cannot happen in a root file. This felt counter-intuitive to me, and manifested as a `ReferenceError: harden is not defined` (and might be nice to suggest a link to standard lockdown practices in response to this error).

Example of something that won't work:
```javascript
import 'ses';
lockdown();

import '@agoric/eventual-send/shim.js';
import { E, makeCapTP } from '@agoric/captp';
```

The fix:
```javascript
import './lockdown.js'; // Where ses and the lockdown call have been moved
import '@agoric/eventual-send/shim.js';
import { E, makeCapTP } from '@agoric/captp';
```
