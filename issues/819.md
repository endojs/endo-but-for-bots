# #819: Propose ECMA 262 language invariant for proxy handlers

## Description

Proxies currently interact with their handlers strictly by calling `get` and then calling the returned method. The integrity of SES depends on this invariant. If ECMA 262 were amended to interact with a new trap in any other way, the `alwaysThrowsHandler` would not be able to detect the interaction and prevent the use of the new trap, and new traps may introduce vulnerabilities.
