## What is the Problem Being Solved?

A major component of an Endo AI Agent worklet (Capp) for #3021 will be prompt engineering, both for the system prompt, and the tool instructions for executing confined code. The prompt will need to guide the LLM to  create tool responses that are executable in a JavaScript environment without modification. The tool will need to provide useful diagnostic feedback if execution fails. The LLM will need some basic instructions for use of Endo-specific design patterns like eventual send, the presence of certain lexical variables, and the way in which it can use further tool calls to directly inspect any of the capabilities it has already accumulated.

Prompts do not tend to port between models, so the prompt should be clearly marked for usage with a specific LLM. We have had good initial observations with Qwen3.
