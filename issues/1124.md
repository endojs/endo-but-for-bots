## Description

In StaticModuleRecord, we have calls to `path.buildCodeFrameError` that throw a reference error because there is no `path.hub` property on new AST identifier nodes. I believe the `path.hub.buildError` is absent, because the Babel types are not associated with a document when we set up our Babel plugins. There is presumably some missing Babel ceremony to associate Babel types with a document. We should test the error message for identifier censorship to verify the fix.
