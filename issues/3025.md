## Description

## What is the Problem Being Solved?

Currently, pet dæmon “guests” do not receive the power to `evaluate` code. This needs to be upgraded so that the guest can propose a program and this gets translated to mail to the host, where they can allow or deny the request.

## Description of the Design

## Security Considerations

Ideally, we avoid asking the user yes/no questions. We might be better able to frame this with a code editor and “evaluate” or “reject” buttons, then communicate the user’s choice back to the LLM.
