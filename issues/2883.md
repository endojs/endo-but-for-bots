## What is the Problem Being Solved?

#2871 introduces the name `compareRankRemotablesTied` as the name for what used to be default semantics for `compareRank` we had before https://github.com/endojs/endo/pull/2597 . I remember looking at #2597 at the time and thinking it was ok for the short circuiting behavior to be the new default. We do need the short circuiting option, I no longer think it should have been the default. If we didn't have the compat worry, I would restore the `compareRankRemotablesTied` as the default behavior and call the #2597 behavior something else.

See https://github.com/endojs/endo/pull/2871/files#r2201446324 for more.

Now that we have both options, we need to figure out which calls to `compareRank` should really be calls to `compareRankRemotablesTied`
