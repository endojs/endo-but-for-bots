## Description

Friend @jcorbin gave the [Escape Room](https://github.com/endojs/endo/tree/master/packages/ses/demos/challenge) a whirl and had some frustrating experiences:

1. Errors, like syntax errors, do not get reported to the console in a timely fashion.
2. In general, programs seem to hang without feedback.
3. Although SES denies Math.random in general, injecting a deterministic Math.random for the escape room may be handy for some experiments without making the room more escapable.

To reproduce a hang, consider:

```js
function* hello() {
  console.log(Math.random());
}
```

Other minor issues:

- Josh also believes, in the timing example, the function `fastestChar` should actually be `slowestChar`.
- The page text purports that `guess()` returns a `Promise`, but the code samples are not consistent with that claim.
