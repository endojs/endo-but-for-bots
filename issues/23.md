### @rekmarks (MEMBER) — 2020-07-13T18:55:57Z

What's the official word on Web Worker support?

The following snippet appears to work in a dedicated worker in Chrome, with `ses@0.8.0`:

```javascript
import 'ses';
 
const c = new Compartment({
  print: harden(console.log),
});
 
c.evaluate(`
  print('Hello! Hello?');
`);
```

"Appears to work" meaning, no errors are thrown, and the message is logged to the console as expected.

The [current docs](https://github.com/Agoric/SES-shim/blob/master/packages/ses/docs/source/getting-started.md), state that Web Worker support won't happen until the Realms proposal is implemented, but they seem to refer to `ses@0.6.x`.

### @erights (MEMBER) — 2020-07-13T19:09:54Z

Hi @rekmarks thanks for catching this. Yes, SES should in theory work fine in a web worker except that we've done zero testing of that.

We faced two environments that had no support for multiple realms: Web Worker and XS. That was one of the motivations for fully separating Realms from SES, which is now done.

I will remove that mistaken part of the documentation. However, I'm going to leave this issue open for now, as zero testing hardly qualifies as "support" ;). OTOH, Agorics has no immediate need for Web Workers, so I doubt we'll test that soon. If you do, please let us know. Thanks!
