## Description

Setting the prototype of namespaces should be disallowed. 

**Steps to reproduce**

In `make-importer`, replace `moddir/index.js` with:
```js
export const foo = null;
import * as ns from './index.mjs';
var newProto = {};

let err;
try {
  Object.setPrototypeOf(ns, newProto);
} catch(e) {
  e = err;
} finally {
  if (err instanceof TypeError) {
    console.log('setting prototype of namespace is disallowed');    
  } else {
    throw 'should not allow setting prototype of namespace';
  }
}
```

Then execute:
```sh
$ node -r esm test/test-moddir.js 
TAP version 13
# moddir index.js
not ok 1 unexpected exception
  ---
    operator: notEqual
    expected: 'should not allow setting prototype of namespace'
    actual:   'should not allow setting prototype of namespace'
```

Expected result: no error. See the reference.
https://test262.report/browse/language/module-code/namespace/internals/set-prototype-of.js

This is something we should flag to esm:
```
$ node --trace-uncaught -r esm test/moddir/index.js
should not allow setting prototype of namespace
Thrown at:
```
And node native modules:
```
$ echo "import { foo } from '/Users/jfparadis/projects/make-importer/test/moddir/index.mjs';" |   node --experimental-modules --input-type=module
(node:42292) ExperimentalWarning: The ESM module loader is experimental.
should not allow setting prototype of namespace
```
