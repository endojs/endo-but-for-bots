## Description

Modules can be visited more than once when resolving bindings through "star" exports as long as the exportName is different each time.

**Steps to reproduce**
In `make-importer`, replace `moddir/index.js` with:
```js
import { x } from './mod1.js';
console.log(x);
```
Replace `moddir/mod1.js` with:
```js
export * from './mod2.js';
```
Replace `moddir/mod2.js` with:
```js
export { y as x } from './mod1.js';
export var y = 45;
```

Then execute:
```sh
$ node -r esm test/test-moddir.js 
```
Actual result:
```
$ node  -r esm test/test-moddir.js 
TAP version 13
# moddir index.js
not ok 1 unexpected exception
  ---
    operator: notEqual
    expected: |-
      [SyntaxError: The requested module 'file://~/projects/make-importer/test/moddir/mod1.js' does not provide an export named 'y']
    actual: |-
      [SyntaxError: The requested module 'file://~/projects/make-importer/test/moddir/mod1.js' does not provide an export named 'y']
    at: Test._387‍.r.test (~/projects/make-importer/test/test-moddir.js:61:7)
    stack: |-
      SyntaxError: The requested module 'file://~/projects/make-importer/test/moddir/mod1.js' does not provide an export named 'y'
          at instance.initialize.then (~/pr
```
Expected result, same as node's native import:
```sh
$ node -r esm test/moddir/index.js
45
```
