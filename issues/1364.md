## Description

compatibility issue with [tslib@1.14.1](https://npmfs.com/package/tslib/1.14.1/)

package.json defines unusually and maybe invalid exports field that defines both '.' and './' https://npmfs.com/package/tslib/1.14.1/package.json
```json
    "exports": {
        ".": {
            "module": "./tslib.es6.js",
            "import": "./modules/index.js",
            "default": "./tslib.js"
        },
        "./": "./"
    }
```
