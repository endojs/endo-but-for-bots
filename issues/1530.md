## Description

Recent performance analysis shows a lot of time spent in [`assert.quote`](https://github.com/endojs/endo/blob/916f6d42270b282641d3299abdb4ca9c835a039b/packages/ses/src/error/assert.js#L50), and I wonder if there's misattribution of [`bestEffortStringify`](https://github.com/endojs/endo/blob/916f6d42270b282641d3299abdb4ca9c835a039b/packages/ses/src/error/stringify-utils.js#L84), which can probably be sped up a great deal by bypassing `JSON.stringify`.
