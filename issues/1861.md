## Description

## What is the Problem Being Solved?

Sometimes pending changes are needed by downstream consumers before they're in an Endo release. E.g. https://github.com/endojs/endo/pull/1850

## Description of the Design

Build and publish pre-release versions.

agoric-sdk publishes on each commit to master in [its dev-canary job](https://github.com/Agoric/agoric-sdk/blob/master/.github/workflows/after-merge.yml#L35-L75). https://www.npmjs.com/package/agoric?activeTab=versions shows the versions (`{next-version-number}-dev-{gitSha}`). 

Publishing nightly would also suffice. That numbering scheme could be `{next-version-number}-dev.YYYYMMDD` (like [TypeScript has](https://www.npmjs.com/package/typescript?activeTab=versions)).
