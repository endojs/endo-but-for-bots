## Description

Enabling any kind of automated tracing or debugging in the Agoric SwingSet kernel process causes `async_hooks` to be triggered, which required mitigations to be added to endo (#1115).

However since then endo added a `unsafe-fast` init, which fakes harden. While that doesn't alleviate the need for the `async_hooks` mitigation, it may be possible to reduce the intrusiveness of the mitigation in that case.

In particular, we should avoid putting accessors for the symbols on the promise prototype that end up getting invoked for every single promise created. The tricky bit is that pass-style has special logic for these prototype symbol properties, and permits only allow an accessor. If we could parametrize the permits, maybe a solution would be to put the symbols as data properties (with an `undefined` value). Or maybe we can avoid the whole permits addition in the first place if we arrange the async_hooks mitigation to run as a [vetted shim](422)
