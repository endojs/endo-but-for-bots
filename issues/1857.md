## Description

## What is the Problem Being Solved?

Writing a library for Hardened JavaScript benefits from the Endo eslint tools and project scaffolding. We should make this available to packages outside of the Endo workspace.

(Provoked by @JimLarson)

## Description of the Design

We have an `endo/packages/skel` that we use to create new packages, in turn with the `scripts/create-package.sh`. Npm and Yarn answer this question with conventionally named `create-x` packages, e.g., `create-react-app` or `create-endo-lib`. We can use this infrastructure to export `@endo/skel` and the behavior of `scripts/create-package.sh` to third-party developers.
