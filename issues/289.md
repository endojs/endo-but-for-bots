Thank you @inf3rno. We’ll be sure to at least clarify that this project pertains primarily to safely executing third-party **JavaScript**. SES turns a JavaScript “realm” into a “frozen realm” that prevents third-party code from staging man-in-the-middle attacks on other code by subverting shared global state like the Object prototype.
