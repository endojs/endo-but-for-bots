## What is the Problem Being Solved?

We can write a pattern for a discriminated union using `M.or()`, but when a match fails, the diagnostic isn't specialized to any branch of the union.

## Description of the Design

Where we can now write...

```js
M.or(
  {kind: 'animal', eats: FoodShape},
  {kind: 'vegetable', lifetime: M.number()},
  ...
);
```

if we could write...

```js
M.choose('kind', [
  {kind: 'animal', eats: FoodShape},
  {kind: 'vegetable', lifetime: M.number()},
  ...
])
```

Then perhaps a diagnostic for `{kind: 'animal', lifetime: 3}` could say "property eats missing" rather than just "didn't match".
