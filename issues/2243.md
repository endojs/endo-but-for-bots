## What is the Problem Being Solved?

In https://github.com/endojs/endo/pull/2240 we dropped Windows CI support. To restore Windows CI support, we would need:

- [ ] Solve graceful CapTP disconnection https://github.com/endojs/endo/issues/2242
- [ ] Possibly, Yarn 4 support for Windows https://github.com/endojs/endo/pull/2222

To _value_ Windows support, we would need a product that can only run with `node.exe` in Windows. We _speculate_ that this would be useful for an Electron app or similar housing around the pet daemon.
