## Description

We already whitelist `String.prototype.replaceAll` from ES2021. But apparently, this or related proposals introduced new anonymous iterator-prototype intrinsics? By "anonymous intrinsic" we mean, any primordial object that is not discoverable simply by dotted naming path starting from the global. Several other iterator prototypes, like `%MapIteratorPrototype%` are already known anonymous intrinsics that we gather.

However, if we whitelist an operation that enable access to an anonymous intrinsic that we did not know to gather, that would provide allegedly confined code with access to a shared mutable object enabling both information and capability leaks.
