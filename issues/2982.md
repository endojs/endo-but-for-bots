## Description

## Describe the bug

bundles modules, at least in the `nestedEvaluate` format, encounter reference errors when assigning to an exported `let` binding.

## Steps to reproduce

See `let-export.test.js` from https://github.com/endojs/endo/pull/2980

## Expected behavior

Correct `export let` semantics for bundled modules

## Additional context

Originally encountered when reproducing https://github.com/endojs/endo/issues/2981
