# #2128: daemon: Consider using content address as `readable-blob` formula id

- **URL:** https://github.com/endojs/endo/issues/2128
- **State:** OPEN
- **Author:** @rekmarks
- **Created:** 2024-03-09T01:05:36Z
- **Updated:** 2024-04-17T05:48:19Z
- **Labels:** `enhancement`, `daemon`

## Description

The `readable-blob` formula corresponds to some binary data. We store its content address, a SHA-512 hash, as part of the formula. We should consider simply the content address, which has the same format as our ids, as the formula id.
