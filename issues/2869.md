## Description

## What is the Problem Being Solved?

`await E(anything)` is forever-pending because `EProxy` captures `then` as a method invocation but doesn’t use the given callback or errback to settle the resulting native promise. The `then` method is not useful, would be harmful if it were used, and from this emerges a terrible footgun.

## Description of the Design

Create a pinhole for `then` in the `EProxy` handler. Consider inverting that with an `E.then` symbol that can be used if the object has a legitimate `then` method (and ensure that Exos also define their `then` method with `E.then`, or rather `Symbol.for('then')` so that exos are not themselves ever thenable)
