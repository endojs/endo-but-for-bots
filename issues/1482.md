## Description

LavaMoat supports a string `'write'` as value for a global specified in a policy. It allows the package to write to that global.
The feature is not very popular but needed by some of the packages in the ecosystem.

What gets modified when writing to globals is a copy that was made for endowing into compartments, not the original global.
