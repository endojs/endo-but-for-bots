## Description

For any feature needing support for source to source JavaScript translators, we will need separate translators for the program to program translation (for evaluate) and the module to module translation (for importHook).

The program to program translator needs to be fed to the Compartment constructor and the module to module translator needs to be implemented by the creator of the importHook. The reason the Compartment needs to be aware of the program to program translator is that it might be run ad-hoc by `eval` within the compartment.
