### @kriskowal (MEMBER) — 2025-05-20T22:23:03Z

This is a low-probability flake that we’ve tolerated for a while (but I cannot find an earlier issue to track it!). This particular flake occurs much more frequently on Windows, so we disabled Windows CI until we can figure this out. The problem appears in CapTP over Node.js with Node.js streams and is likely because we do not gracefully handle every order of events on Dæmon shutdown or a closed connection.
