## Description

Some @endo packages export types ambiently. This leads to problems downstream like https://github.com/Agoric/agoric-sdk/issues/4560

Some examples:
- `Module '"@endo/promise-kit"' has no exported member 'isPromise'`

Instead @endo packages should export types explicitly as in https://github.com/endojs/endo/pull/1025/
