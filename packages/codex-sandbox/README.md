# `@endo/codex-sandbox`

A bounded Endo capability adapter for the official Codex app-server protocol.
It keeps Codex-specific JSON-RPC and process lifecycle details out of consumers
such as Floot.

This package intentionally does not provision containers, project mounts, or
credentials. A caller creates one confined `@endo/sandbox` slice per session,
then supplies a transport factory:

```js
import { makeCodexClient } from '@endo/codex-sandbox';
import { startAppServerTransport } from '@endo/codex-sandbox/app-server-transport.js';
import { E } from '@endo/eventual-send';

const client = makeCodexClient({
  sessionId,
  start: () => startAppServerTransport({ slice, cwd: '/workspace' }),
  threadId: storedThreadId,
  saveThreadId,
  reportCleanupFailure: recordOperatorAlert,
});

const reader = await E(client).send('Review the current changes');
```

`send()` returns an Endo reader of provider-neutral events:

- `phase`
- `commentary-delta` (progress only; do not persist or speak as the answer)
- `text-delta`
- `tool-call`
- `tool-result`
- `usage`
- terminal `end` or `abort`

Only one turn may run at a time. Closing the reader interrupts that exact turn;
a second concurrent `send()` is rejected. `models()` reads the app-server model
catalog rather than relying on hard-coded model or reasoning-effort lists.

The container recipe pins Codex CLI 0.152.0. Protocol changes must be reviewed
against schemas generated by that exact binary with
`codex app-server generate-json-schema` or `generate-ts` before updating the
pin.

The process transport also exposes bounded stderr diagnostics and `wait()` to
its owning provisioner. `CodexClient` deliberately does not place untrusted
process diagnostics into the model/reply event stream; a caller that needs
operator diagnostics should retain the transport it created in `start()`.
`reportCleanupFailure` must write late teardown failures to operator-visible
telemetry; they are also retained in the client's bounded `status()` result.

Read [SECURITY.md](./SECURITY.md) and [MERGE-BLOCKERS.md](./MERGE-BLOCKERS.md)
before adding a provisioner.
