# `@endo/benchmark`

This package just provides a minimalistic ava-like interface to run benchmark tests. 

## How to run locally
Run the command `npm run test` in the `packages/benchmark` folder.

## Pre-reqs of running `npm run test`
Run the command `npm run install-engines` to ensure installation of V8 and XS engines in $HOME/.engines for this package's `eshost`.
