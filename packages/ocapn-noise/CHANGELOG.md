## Unreleased

Pre-release (`0.1.0`, unpublished). Current capabilities in the tree:

- A **Noise Protocol** netlayer for `@endo/ocapn`
  (`Noise_IK_25519_ChaChaPoly_BLAKE2s`), dial-by-Ed25519-identity, with the
  cryptography implemented in Rust compiled to WebAssembly (`rust/ocapn_noise`).
- One network (`makeOcapnNoiseNetwork`) carrying many identities, routing
  inbound sessions to the addressed local key.
- Transport plugins: `transport/mock` (in-process test pair), `transport/tcp`
  (Node `net`), `transport/ws` (WebSocket, Node variant today), and
  `transport/iroh` (dial-by-pubkey QUIC over `@number0/iroh`, an
  `optionalDependency` — no `host:port`, no open TCP listeners, NAT
  traversal + relay; see `IROH-MIGRATION.md`).
