Captured 2026-07-11 from host i-0380cd68b90020fad (aarch64, Ubuntu 24.04) via SSM.

A local peer reaches the DEPLOYED full Pet Daemon's EndoOcapnBootstrap (swissnum
`endo-bootstrap`) over the public wss://minion.town/ocapn-daemon endpoint. The
daemon runs as a Docker container (image endo-pet-daemon:ocapn-ws) built by
packages/daemon/deploy/Dockerfile; Caddy on :443 reverse-proxies /ocapn-daemon
