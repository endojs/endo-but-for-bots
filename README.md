# Live eval transcripts

This branch is an append-only publication channel for live-eval transcripts.
It never merges with any code branch, and PR comparisons against it are
meaningless. Append-only discipline keeps previously shared pinned links alive.

New publications use date-first campaign folders described in [FORMAT.md](FORMAT.md).
Start at [INDEX.md](INDEX.md), then open a campaign README for the scenario
tables and transcript links. Retried model/scenario attempts are kept beside
the original attempt and are linked together from the report.

The historical hash-first paths remain unchanged. This branch must not contain
a .github/ directory, so transcript publication never triggers repository
workflows.
