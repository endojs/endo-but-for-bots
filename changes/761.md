## Summary

- **What:** Patches `@lerna/conventional-commits` so version recommendations and CHANGELOG generation respect npm's `^0.x` semantics (paralleling agoric-sdk#3230).
- **Why:** Without the patch, `feat:` would bump 0.x.y to 0.(x+1).0, breaking caret-range consumers; this lets pre-1.0 packages bump only on `!`.
- **Themes:** release, tooling, chore
- **Status:** merged

## Description

This change parallels https://github.com/Agoric/agoric-sdk/pull/3230 and configures Lerna to behave consistently with the npm semantics of `^0` dependencies, both for recommending versions and building a change log based on conventional commits.
