## Summary

- Rebases LLM agent infrastructure (llamadrome, capability-separated evaluation) onto the `kriskowal-daemon-collector` branch
- Adds three new message types (`eval-request`, `definition`, `form-request`) to the daemon mail system
- Implements `define`/`endow`/`form` verbs for capability-separated code evaluation
- Includes Anthropic backend with tool calling, conversation persistence, and restart recovery
- Drops `threadId` in favor of collector's `messageId`/`replyTo` system
- Completes least-authority exo with all required interface methods
