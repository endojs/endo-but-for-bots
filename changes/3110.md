## Description

We have wanted to unbundle assert and console from ses, so, for example, others could use @endo/errors without pulling in ses. But untangling assert from console would take more work than I'm willing to spend right now. The ses/src/errors directory contains both assert and console entangled. Fortunately, I took a look at all imports in this directory, and I saw very little dependence on the rest of ses. So this PR will 
- [x] start by moving ses/src/error to error-console-internal/src.
- [x] refactor ses to depend on error-console-internal instead of its ses/src/error directory.
- [x] refactor @endo/errors to depend error-console-internal instead of ses

The package name uses "internal" because it is not meant to be imported by anything other than ses and @endo/errors. 

- [x] ~Ideally @endo/error-console-internal would not be published to npm, though I will need help with that.~
  Addendum: https://github.com/endojs/endo/pull/3110#issuecomment-3982096134 convinced me to give up on that.
