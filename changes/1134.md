## Summary

- **What:** Adds `@endo/compartment-mapper` support for the array-of-alternatives form in `package.json` `exports` (both string and object alternatives), iterating to find the first non-empty match.
- **Themes:** compartment-mapper, ecosystem-compat
- **Status:** merged

## Description

There's no point in iterating the array, because in the top 1000+ packages with exports field defined as an object, all examples using an array define the same export twice in the array - once as an object with default/import alternatives and another as string.

We support both ways, so taking `[0]` is enough of an alternative choice algorithm.
