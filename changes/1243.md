## Summary

- **What:** Removes the dead `environment-options.js` module from `@endo/marshal` and adds a missing `freeze()` so the `ses` `environment-options` module is safe to use after lockdown.
- **Themes:** ses-lockdown, marshal, chore
- **Status:** merged

## Description

The environment-options.js file in @endo/marshal is similar to the one in @endo/ses. The biggest difference is that the one in ses is designed to be used before lockdown, whereas the one marshal is designed to be used after lockdown. But no one does. This module is unmentioned within its package and its exports are not reexported from its package. Thus, deleting it should have no effect.

We should have something like this that can be used after lockdown. But I'd much rather just use the one in @endo/ses, and have lockdown change it so that, after lockdown, it can be used safely with the same meaning. That hypothetical change is not part of this PR.

Since this PR is only removing dead code, there's no security implication and nothing to test or document.
