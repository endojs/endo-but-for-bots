## Summary

- **What:** Adds `"./package.json": "./package.json"` to each Endo package's `exports` map so Node 12/14 strict ESM resolution lets tooling (Rollup, Svelte) read each package's manifest.
- **Themes:** chore, ecosystem-compat, release
- **Status:** merged

## Description

This is needed by tooling like Rollup, when used in conjunction
with the latest Node 12.x and 14.x branches.
