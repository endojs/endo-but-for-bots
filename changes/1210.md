## Summary

- **What:** Adds `@endo/base64` exports for `atob`/`btoa` and an `@endo/init` shim that installs them as globals; updates `pre-node` exports.
- **Why:** Libraries like `protobufjs` rely on global `atob`/`btoa` when `Buffer` is unavailable (web-compatible path).
- **Themes:** ses-lockdown, ecosystem-compat
- **Status:** merged

## Description

These are useful and standard Web/Node.js APIs for Base64 support.

At least `protobufjs` relies on having them in the global scope (Web-compatible) when `Buffer` is unavailable.
