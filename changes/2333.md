## Summary

- **What:** Reverts the `browser-test` CI job from the Selenium Chrome-nightly Docker image back to the default container, accepting stale Chrome until system deps are restored.
- **Why:** Playwright was failing in CI because the Selenium image lacked required system dependencies.
- **Themes:** ci, tests, tooling
- **Status:** merged

## Description

The Selenium Docker image with Chrome nightly builds is no longer sufficient for Playwright CI for lack of some system dependencies. This change mitigates the problem by walking back to the default container image until we can prepare a working Docker image for Chrome nightlies.
