## Summary

- **What:** Extends `@endo/evasive-transform` to accept external Babel visitors so callers can add transforms without re-parsing the AST, and adds evasion for class methods/object methods named `import` and `eval`.
- **Why:** Lavamoat needed to compose its own transforms onto an already-parsed AST and to mask additional reserved-word methods.
- **Themes:** compartment-mapper, bundle-source, tooling
- **Status:** merged

## Description

## Description

- add extensibility - so it's possible to externally add a transform visitor to be applied on the AST, since it was already parsed and it's best to not parse again if someone wants to add more transforms
- add a simple class field transform I found I need
