## Summary

- **What:** Defers `ses` Compartment `moduleMap` resolution to load time instead of eager translation in the constructor (constructor still does early-error validation), preparing the surface for a `moduleMapHook` and cyclic cross-compartment dependencies.
- **Themes:** ses-lockdown, compartments
- **Status:** merged

## Description

Prior to this change, the Compartment constructor translated the module map into aliases.  After this change, the compartment loader addresses the module map on demand.  Some validation remains in the constructor for early errors when possible.  This change prepares the Compartment for a dynamic module map hook, necessary to emulate wildcard linkage for Node.js packages, and also sufficient to enable cyclic dependencies among modules in separate compartments.
