### @kriskowal — CHANGES_REQUESTED — 2020-09-09T21:30:52Z

`harden-integration-test` does appear to be vestigial to me. I cannot find a `test/test.js`, which the bundler scripts refer. It seems to me like this was only scaffolded, but I would like @katelynsills to weigh in on whether this is truly dead.

Because `harden` and `make-harden` are published packages, we should instead of deleting this packages outright, deleting everything but a tombstone `package.json` and `README.md`, one breaking change version up, and republish. This will require trimming down `package.json` too. This will leave a tombstone on `npm` with clear migration instructions. In this case, `harden` is provided exclusively by `ses`, since it is not useful pre-lockdown.

I expect we will want to keep the `NEWS.md` for the published/deleted packages, expecially `harden` since they will provide continuity if we create a new version to shim `harden` on XS.
