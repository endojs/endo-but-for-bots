## Summary

- **What:** Always stops the `@endo/daemon` daemon process during `purge`, even if it was running, since any subsequent CLI command will start it again on demand.
- **Themes:** daemon, cli

## Description

Ensures that the daemon is not restarted after being purged, even if it was previously running. Any CLI command will simply restart the daemon anyway.
