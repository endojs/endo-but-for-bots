## Summary

- **What:** Introduces a `ses` module loader that resolves `ModuleStaticRecord`s into `ModuleLinkageRecord`s while traversing imports across Compartments.
- **Why:** Required for `Compartment.import` to work across the inter-compartment module graph.
- **Themes:** ses-lockdown, compartments
- **Status:** merged

## Description

The loader is responsible for loading ModuleStaticRecords and from them deriving corresponding ModuleLinkageRecords (no explicit constructor) with references to the records of the modules they import. The loader must be able to transit links to other compartments.

### @kriskowal (MEMBER) — 2020-04-30T22:55:40Z

My feeling, given the layering, is that linkageRecord might be a misnomer. The linkage record is the output from the load phase and the input of the link phase. It is still as static as a module static record, but now has its import specifiers resolved in the context of its compartment, and is paired with that compartment. I think “Module Compartment Record” might communicate its purpose more clearly.
