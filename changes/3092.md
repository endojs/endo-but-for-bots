## Summary

- Fixes 14+ daemon test failures on the `llm` branch by addressing re-entrant collection, concurrent cancellation races, API mismatches, and lint issues
- Daemon tests: 95/98 pass (up from ~81). The 2 remaining timeouts (`unconfined/confined service can respond to cancellation`) are pre-existing hangs from `origin/llm` caused by a deeper `withCollection` timing issue

## Changes

### Re-entrant collection guard (`daemon.js`)
- `collectIfDirty()` now returns immediately when `formulaGraphLockDepth > 0`, preventing newly-created sub-formulas from being collected during formulation when the graph is temporarily incomplete

### Graceful cancelled context handling (`context.js`)
- `thatDiesIfThisDies` and `onCancel` no longer `assert(!done)` -- they silently return when the context is already cancelled
- This handles the race where concurrent CapTP dispatch causes dependency registration on already-cancelled formulas

### Name path support in `request()` (`mail.js`)
- `request()` now accepts name paths (arrays) for response storage via `namePathFrom()`, matching the pattern already used by `requestEvaluation()`

### Test fixes (`endo.test.js`)
- Updated 5 `makeUnconfined` call sites to use the new options object API
- Fixed BigInt message number assertion (`0` -> `0n`)
- Fixed race in pet name path test by awaiting `requestP` before lookup

### Lint fixes (`chat.js`, `typedoc.json`)
- Renamed 3 shadowed `$controls` variables to unique names
- Added JSDoc type cast for `restrict-comparison-operands`
- Added `packages/chat` and `packages/lal` to TypeDoc exclusions
