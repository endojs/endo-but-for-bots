## Summary

- **What:** Restores `@endo/compartment-mapper`'s test-fixture maker and re-permits a sentinel `modules` map (e.g. `{ builtin: true }`) when archiving, since the values are ignored at archive time even though `importLocation`/`importArchive` require real namespaces.
- **Why:** Regression introduced by the required-exits work in #779.
- **Themes:** compartment-mapper, tests
- **Status:** merged

## Description

… modules from archives


Addresses a regression: archives can be created with a `modules` option for the exit modules of the application. The values of the module map are ignored for the purposes of archiving, so `{ builtin: true }` is acceptable, whereas when passing `modules` to `importLocation` or `importArchive`, the values must be reified module namespace objects.
