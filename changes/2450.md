## Summary

- **What:** Spike adding a `no-ambient-auth` ESLint rule to `@endo/eslint-plugin` that flags modules transitively importing sources of ambient authority (refs agoric-sdk#2160).
- **Why:** Mechanically catch modules that close over powerful stuff and re-export it; assumes "imports powerful → exports powerful".
- **Themes:** tooling, security

## Description
Exploration in support of,
- https://github.com/Agoric/agoric-sdk/issues/2160

Ambient authority is when an export closes over powerful stuff. This makes a simplifying assumption that if a module imports powerful stuff it also exports it. So the detection of ambient authority is merely: does this module transitively import a source of ambient authority?
