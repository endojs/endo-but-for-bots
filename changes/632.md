## Summary

- **What:** Adds an `overrideTaming: 'severe'` lockdown option in `ses` (whole `Object.prototype` plus `TypedArray.prototype`) and trims `'moderate'` back to TypedArray-only.
- **Why:** Restores SES 11-era enablement breadth as an opt-in for LavaMoat-style consumers without burdening the default.
- **Themes:** ses-lockdown, ecosystem-compat
- **Status:** merged

## Description

Adds a `{overrideTaming: 'severe'}` option in addition to the `'min'` and the default `'moderate'` options. The moderate option returns to only reasonably enabling `TypeArray.prototype`. The new `'severe'` option enables everything in `Object.prototype` (as did SES 11) and `TypedArray.prototype` (as the `'moderate'` setting did before this PR).
