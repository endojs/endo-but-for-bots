## Summary

- **What:** Moves the public type definitions for `@endo/stream` into `index.d.ts` so the `Reader`/`Writer` generics can have default templates that JSDoc cannot express, and adds an `@endo/stream-types-test` package to lock the public surface.
- **Themes:** types, captp
- **Status:** merged

## Description

This change ejects certain type definitions from the stream library as they are not fully expressible as JSDoc. Particularly, this allows the reader and writer generic types to have default templates.
