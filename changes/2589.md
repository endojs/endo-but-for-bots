## Summary

- **What:** Make `@endo/ses-ava`'s `wrapTest` recurse through nested ava chains (e.g. `test.serial.only`) wrapping each function level until no known name remains.
- **Why:** Surface error details correctly when consumers chain ava modifiers more than one level deep (refs Agoric/agoric-sdk#10208).
- **Themes:** tests, types
- **Status:** merged

## Description

Refs: https://github.com/Agoric/agoric-sdk/pull/10208

## Description

the `ava` test functions can be nested more than one level deep. This change recurses test functions with known names until none is found.

### Documentation Considerations

Relaxes the type of acceptable test functions as it only really cares about it being a test function, regardless of whatever chain expandos it may have.

This is used by tests only, and can be consumed as a non breaking change simply by using the new NPM package including this fix.
