For #2941 test1, reporting the event when there is no event.error, in the browser, after clicking on the outline-expansion triangle, looks like

<img width="1171" height="501" alt="image" src="https://github.com/user-attachments/assets/b6372215-d9cb-4361-8152-74bc481ebdfd" />

which is still much less informative that the platform's default error logging behavior, but probably the best we can do given the platform's support for user-level error trapping.

### Security Considerations

We were not previously exposing the event itself. Here we're only exposing it to the console, under our standard assumption that only very privileged programs or users can read the console output. So we seem to be safe under that assumption.
