## Summary

- **What:** `@endo/compartment-mapper` adds a `node-powers` adapter and follows symbolic links (using realpath) so dependencies resolve from a module's canonical location, mirroring Node's behavior; also improves the linker error with an actionable hint.
- **Why:** Fixes #774 — without realpath, peer deps of symlinked packages (e.g. `evan` -> `evankin`) failed to resolve.
- **Themes:** compartment-mapper, ecosystem-compat, errors
- **Status:** merged

## Description

Node.js can follow symbolic links and searches for a package's dependencies relative to a module's canonical location, not its logical location from the perspective of the importer.

Fixes #774

- feat(compartment-mapper): Add Node.js power adapter

- feat(compartment-mapper): Follow symbolic links
- feat(compartment-mapper): Add actionable hint to linker error
- doc(compartment-mapper): Clarify parameter names for read and write
