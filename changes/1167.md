## Summary

- **What:** Threads a diagnostic name through `@endo/compartment-mapper` and adds a `@endo/check-bundle` test asserting invalid archives surface a location in the error.
- **Why:** Bundle caches that vend corrupted archives produced opaque errors; a name in the diagnostic helps users find the offending bundle.

- **Status:** merged

## Description

This change improves an error diagnostic that has become common when we introduced a cache that sometimes vended out corrupt bundles.
