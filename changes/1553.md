## Summary

- **What:** Flips `@endo/eventual-send` to default `TRACK_TURNS=disabled` and decouples result-hardening from the track-turns flag.
- **Why:** Track-turns shouldn't be on by default in production; the prior layering also accidentally skipped harden when disabled.
- **Themes:** eventual-send, ses-lockdown, performance
- **Status:** merged

## Description

As discussed at Agoric.

Also, fix a layering mistake in which if `TRACK_TURNS=disabled`, then eventual-send results were not hardened.
