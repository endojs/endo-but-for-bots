## Summary

- **What:** Loosens `ses` source censors to allow `obj.import(...)` and `obj.eval(...)` method calls (only the bare `import`/`eval` token followed by `(` is rejected).
- **Why:** Fixes #664 — the previous regex caught legitimate method names.
- **Themes:** ses-lockdown
- **Status:** merged

## Description

Relaxes the censorship of `import` and `eval` in programs evaluated under SES to specifically allow the use of `import.import()` or `evaluator.eval()` methods.

Fixes #664
