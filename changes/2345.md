## Summary

- **What:** In `ses`, adds XS-compatible module descriptors discriminated by `source`/`namespace` (including loading from a parent compartment) and renames `StaticModuleRecord` to `ModuleSource` throughout the monorepo (refs #400, #2251).
- **Why:** Achieves API parity with native XS Compartments; older descriptor shapes remain supported but deprecated.
- **Themes:** ses-lockdown, compartments, types, ecosystem-compat
- **Status:** merged

## Description

Refs: https://github.com/endojs/endo/issues/400 https://github.com/endojs/endo/issues/2251

## Description

This change introduces support for XS-compatible module descriptors with the discriminating properties `source` and `namespace`, including support for loading a module from the parent compartment.
