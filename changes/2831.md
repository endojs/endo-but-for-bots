## Summary

- **What:** Adds a `require.extensions` stub object to `@endo/compartment-mapper`'s CJS parser whose registered functions throw "Not implemented" when called.
- **Why:** Closes #2825 — packages that read `require.extensions` (without invoking the deprecated handlers) crashed on `undefined`.

## Description

Closes: #2825

## Description

This adds a stub for [`require.extensions`](https://nodejs.org/api/modules.html#requireextensions) to the CJS parser. The idea is to provide something that is not `undefined` so that programs access the object without throwing.

Actual implementation of the function _values_ of `require.extensions` is neither feasible nor planned. If one of the functions is called, it will throw with a "Not implemented" error.
