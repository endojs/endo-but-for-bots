## Summary

- **What:** Renames `@agoric/endo` to `@agoric/compartment-mapper`, extracting the module-gathering library from the broader Endo project.
- **Why:** Reframes `compartment-mapper` as a reusable library other projects can depend on, leaving `endo` itself for future work.
- **Themes:** compartment-mapper, chore
- **Status:** merged

## Description

This change creates an `@agoric/compartment-mapper` package with most of the code originally in `@agoric/endo`. The compartment mapper is a library that other projects can depend upon to take advantage of its ability to gather modules. This is in turn a piece of Endo-to-come, but not the whole.

This change is largely mechanical. I presume an effective review will verify the division of concerns and maybe find missed renames.
