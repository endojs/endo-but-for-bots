## Summary

- **What:** Indentation/refactor preparing `ses` to factor out `makeCompartmentConstructor` so the start compartment and child compartments can use different intrinsics (e.g. unsafe `Math`/`Date` in start, safe in children) and inherit parent module maps; superseded.
- **Themes:** ses-lockdown, compartments
- **Status:** closed-unmerged

## Description

This change prepares for creating unique compartment constructors for two scenarios.

First, allowing the start compartment and shared compartments to use variations on their intrinsics.

For example, the start compartment might keep an unsafe Math, Date, or Error, but child compartments must still be safe.

Second, every child compartment must be able to inherit the static module records of their parent compartment through the compartment constructor module map.

This change only indents the compartment constructor in preparation for these changes.

The shim still creates an initial global compartment constructor without tamed or hardened intrinsics.  A future version of lockdown will replace this compartment constructor.

Fixes https://github.com/Agoric/SES-shim/issues/366

### @phoddie (NONE) — 2020-07-03T17:05:42Z

@erights - The following notes are from Patrick about the current implementation in XS:

Each compartment has its own `Compartment` constructor:

	c1.global.Compartment === c2.global.Compartment: false

All compartments share `Compartment.prototype` and `Compartment.prototype.constructor`

	c1.global.Compartment.prototype === c2.global.Compartment.prototype: true
	c1.global.Compartment.prototype.constructor === c2.global.Compartment.prototype.constructor: true
	
Which is different from their own `Compartment` constructor:

	c1.global.Compartment.prototype.constructor === c1.global.Compartment: false

What XS did not implement was the `Compartment` constructor that always throws. Change committed. Now...

	new c1.global.Compartment.prototype.constructor 

...throws a TypeError. (This will be in the next updated of XS in the Moddable SDK.)
