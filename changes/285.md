## Summary

- **What:** Adds a `ses` module linker that synchronously instantiates and cross-links import/export namespaces once all `ModuleStaticRecord`s have loaded.
- **Why:** Final piece needed for `Compartment.import` to evaluate any subgraph after async load.
- **Themes:** ses-lockdown, compartments
- **Status:** merged

## Description

Provided that a graph of module compartment records has been fully loaded asynchronously, we can then synchronously instantiate and cross-link the import and export namespaces of all those module instances. After linking, we are ready to synchronously execute any subgraph from any entry point.
