## Summary

- **What:** Breaking change in `@endo/netstring`: removes the embedded stream library, depends on `@endo/stream` instead, and aligns the API with the `make*` factory pattern.
- **Why:** Netstring was the proving ground for `@endo/stream`; once validated through `@agoric/xsnap`, the embedded copy can be dropped. Introduces a hard SES dependency.
- **Themes:** captp, ses-lockdown
- **Status:** merged

## Description

The netstring library was a proving ground for `@endo/stream`, validating the API and notion of async iterators as a streaming primitive, giving it exercise as a component of `@agoric/xsnap`. That experiment is successfully concluded and we’re making more stream libraries for the Endo browser.

This change ejects the original embedded stream library and makes use of the new `@endo/stream` package. This is however a breaking change because it introduces a dependency on Hardened JavaScript. I’ve taken the liberty to also align the API with the `make*` pattern used pervasively.
