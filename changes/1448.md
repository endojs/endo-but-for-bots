## Description

Move `tools/arb-passable.js` from `@endo/marshal` to `@endo/pass-style`

`tools/arb-passable.js` mainly exports `arbPassable`, which is a so-called fast-check "arbitrary" for generating Passable values for use in fuzz testing. Even though it is currently only used by tests in `@endo/marshal`, it is defined only in terms of concepts at the `@endo/pass-style` level of abstraction. Any consumer of `@endo/pass-style` may wish to use it to write fuzz tests over all possible Passables.

For example, `test-amountProperties.js` currently defines an `arbAmount` which is supposed to generate arbitrary amounts, for fuzz testing code that operates on amounts. But the current form is too trivial to be useful. 

https://github.com/Agoric/agoric-sdk/pull/6769 moves `arbAmount` to its own similar `tools/arb-amount.js` file, but does not yet repair the triviality of `arbAmount`. To define a good `arbAmount`, it should be built on `arbPassable`. After this PR, it would be able to import `arbPassable` from `@endo/pass-style`
