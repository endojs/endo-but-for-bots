## Summary

- **What:** SES scope-proxy handlers are now constructed with `Object.create(null)` and `Object.freeze`-d, instead of relying on `__proto__` literals.
- **Why:** Sestival audit feedback — frozen handlers reduce the surface area for an attacker to swap a trap mid-flight.
- **Themes:** ses-lockdown, security
- **Status:** merged

## Description

We discovered in review that we’d prefer to use `create` instead of `__proto__` and to freeze proxy handlers, just in case.
