## Summary

- **What:** Replaces `a !== b` with `!Object.is(a, b)` in `@endo/eventual-send` `HandledPromise.shorten` so a `NaN`-resolved promise no longer triggers `TypeError: Invalid value used as weak map key`.
- **Themes:** eventual-send, errors
- **Status:** merged

## Description

We need to be more defensive in the `HandledPromise` innards or else we get the following if `NaN` is shortened:
