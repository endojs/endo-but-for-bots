## Summary

- **What:** Catches serialization errors in `@endo/captp` resolution paths and forwards them via the return path so a sender that resolves a remote promise with a non-remotable observes the error instead of hanging.
- **Themes:** captp, errors, marshal
- **Status:** merged

## Description

Wherein we observe that resolving a remote promise with a non-remotable causes an exception and for the receiver to hang indefinitely. This neat trick promotes the serialization error and stuffs it in the return path so the originator can observe the error.
