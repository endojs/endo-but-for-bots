## Summary

- **What:** Imports the netstring framing reader/writer from agoric-sdk's xsnap internals as a standalone `@endo/netstring` package.
- **Why:** Provides a reusable foundation for framing async binary messages (streaming JSON, non-text) needed by `xsnap` IPC.
- **Themes:** ecosystem-compat, ocapn
- **Status:** merged

## Description

This brings `netstring` into the Endo repository as a stand-alone package. This provides a foundation for framing asynchronous binary messages, like streaming JSON, but also non-text messages.
