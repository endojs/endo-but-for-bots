## Summary

- **What:** Migrates `@endo/eventual-send` types from standalone `.d.ts` files into JSDoc inside the `.js` modules (notably `E.js`), making JSDoc the single source of truth.
- **Why:** Improves DX by keeping types next to implementation; first step in a broader type cleanup.
- **Themes:** eventual-send, types
- **Status:** merged

## Description

This PR refactors all types in `@endo/eventual-send` into their respective `.js` modules. The changes are internal and do not affect or alter any other packages in the monorepo.

**Motivation**: Moving towards `jsdoc` being the single source of truth with `.d.ts` files only to improve the overall development experience.
