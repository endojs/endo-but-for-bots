## Summary

- **What:** One-line `@endo/marshal` change to avoid bigint literals (e.g., `0n`) in `makeMarshal` so it parses under Google Apps Script.
- **Why:** Refs #1582; GAS's V8 fork has bigints at runtime but rejects bigint literals at parse time. Open over questions about whether GAS compatibility is a stated product requirement and how supervisor-bundle deployment interacts with such changes.
- **Themes:** marshal, ecosystem-compat
- **Status:** open / under review

## Description

Ref #1582

This doesn't fix the redefined issue, but hopefully does remove the incompatibility that originally prompted it.
