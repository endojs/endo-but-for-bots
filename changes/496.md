## Summary

- **What:** Removes the unfinished `make-hardener-integration-test` package, whose tests never actually ran due to a tape entry-script spelling bug.

- **Themes:** tests, chore
- **Status:** merged

## Description

The integration test for `make-hardener` is in a sorry state.

- Its tests report that it passes, because `tape` silently ignores a spelling error in the test entry script.
- The tests themselves do not run
- Further investigation shows that the entire package is scaffolded but never completed. It has never served its intended purpose.

Given that it’s broken, it should not be on master. I’ve proposed this change to remove the broken package and created a branch that reverts this change and contains all of the work I’ve done to make progress toward getting it running so-far.

https://github.com/Agoric/SES-shim/compare/wip-make-hardener-integration-test

There is no code in the scaffolded project that is specific to running the tests for `make-hardener`, and is otherwise a copy-paste of another integration test. To make progress on this, we’re more likely to meet success by getting more leverage out of the existing `ses-shim-integration-test`, either subsuming harden tests into that fixture, or duplicating that package and modifying a known-working template.
