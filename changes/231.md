## Summary

- **What:** Fixes the SES tame `RegExp` so it can be called as a function without `new`, and re-enables 8 previously failing test262 cases (closes #230).
- **Why:** Plain `RegExp(...)` calls were throwing `undefined is not a constructor`, forcing many packages to set `noTameRegExp: true`.
- **Themes:** ses-lockdown, ecosystem-compat, tests
- **Status:** merged

## Description

Somehow we were only testing `new RegExp()`, and not plain `RegExp()`. The latter was failing with an `undefined is not a constructor` error, which broke a lot of packages unless `noTameRegExp: true` was set.

Thanks to @erights for the recommended patch.

closes #230
