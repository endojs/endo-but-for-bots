### @kriskowal — COMMENTED — 2021-05-18T00:35:37Z

We need a benchmark (and to run the bench on XS) and also should exhaust some of the more obvious ways to make harden faster, like avoiding allocation of closures and stack frames. We don’t benefit from an inlining optimizer on XS. We can convert `forEach` to `for(;;)`. It’s worth experimenting with flat arrays instead of sets for small sizes.

It might even be worth doing a pass without path tracking, then revisit the object graph before committing if we need paths to emit an error.

Since this is for emergency release, I’m amenable to landing this after we have some evidence that there is a performance improvement in production instead of a benchmark.
