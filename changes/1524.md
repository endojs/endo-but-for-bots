## Summary

- **What:** Splits the eslint plugin/config so `plugin:@endo/internal` carries the monorepo's custom rules and `@endo` reverts to a friendlier external-consumer config; removes the now-unused `@endo/eslint-config` dep and fixes lingering lint.
- **Why:** Lets external repos extend `@endo` without inheriting strict internal-only rules and prepares ground for a Jessie integration test.
- **Themes:** tooling, ci, ecosystem-compat
- **Status:** merged

## Description

This is mainly to separate the `"plugin:@endo/*"` eslint configs so that it's possible to extend `"plugin:@endo/internal"` internally to the monorepo for all the custom rules, and restore `"@endo"` only for use by external repos that want endo style and sensibilities without breaking their package.

I will soon be adding an integration test for https://github.com/endojs/Jessie in a general framework to check Endo's viability for a release that doesn't break some downstream clients, but that's for a later PR.

Best viewed commit-by-commit.
