## Summary

- **What:** Adds `tsd` as a type-test runner, replaces ad-hoc Ava type assertions with `*.test-d.ts` files for `ses` and `@endo/eventual-send`, and migrates `jsconfig` to `tsconfig` in those packages.
- **Why:** Closes #1118 — give types a real CI harness so regressions can be caught.

## Description

fixes #1118 

- adds a new test runner, https://github.com/SamVerschueren/tsd/
- changes the Ava tests for types to use it
- changes jsconfig to tsconfig in packages using tsd so it can find it
- fixes some misc TS issues found in the course of the above

Incidentally, any concerns with using `tsconfig` instead of `jsconfig` throughout the repo? If we did that all tooling would find it automatically.
