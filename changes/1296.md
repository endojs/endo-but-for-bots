## Summary

- **What:** Strips the longest common prefix from emitted pathnames in `@endo/bundle-source` `getExport` and `nestedEvaluate` formats and makes `nestedEvaluate` API-compatible with `getExport` for start-compartment evaluation.
- **Why:** Removes filesystem-location sensitivity so bundles are deterministic regardless of the absolute path of the source tree.
- **Themes:** bundle-source, performance
- **Status:** merged

## Description

Remove pathname sensitivity from the `getExport` and `nestedEvaluate` bundle formats by trimming the longest common prefix from emitted output names. 

Also, make the `nestedEvaluate` format backwards compatible with `getExport` when evaluating code in the start compartment.
