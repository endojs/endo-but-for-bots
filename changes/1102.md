## Summary

- **What:** Continues type tightening for `@endo/eventual-send` `E` and `@endo/captp` `Trap`, renames `Remote` to `FarRef<T>`, stamps `Remotable` returns with `RemotableBrand<L,R>`, and improves promise-unwrapping typing.
- **Themes:** eventual-send, captp, marshal, types
- **Status:** merged

## Description

These improve the typing of `E` and `Trap` to be more accurate.

Also, introduce `FarRef<T>` as an "I can handle near, far objects and promises for them" type.
