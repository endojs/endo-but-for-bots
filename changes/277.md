## Description

BREAKING-CHANGE: This module can no longer be used as a CommonJS module, ESM shim module (-r esm), or script tag program.  This reduction in support will simplify Compartment import support as that requires the inclusion of Babel as a dependency, which has proven difficult to bundle for non-ESM usage.
