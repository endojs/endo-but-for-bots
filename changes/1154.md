## Summary

- **What:** Pins `@endo/bundle-source` to a fixed `rollup` tarball that includes the upstream `magic-string` patch for an `Object.prototype.hasOwnProperty` override-mistake hit when bundling under SES.
- **Why:** Rollup's published version had not yet picked up the `magic-string` PR #194 fix, causing `TypeError: Override property hasOwnProperty` for users of `bundle-source` under lockdown.
- **Themes:** bundle-source, ses-lockdown, errors
- **Status:** merged

## Description
