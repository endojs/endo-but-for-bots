## Summary

- **What:** Renames `assemble` to `link` (and `assemble.js` to `link.js`) inside `@endo/compartment-mapper`.
- **Why:** Reviewers found `link` more accurate as a compiler metaphor: the function builds the working-set module graph before archiving or initialization.
- **Themes:** compartment-mapper, chore
- **Status:** merged

## Description

Conversations with contributors revealed that `link` much more clearly describes the `assemble` function, if read as a metaphor for a compiler. The linker builds a graph of all the modules in the working set of an application, prior to constructing an archive or initializing the modules directly.
