## Summary

- **What:** Refactors `@endo/compartment-mapper`'s `makeShortestPath`/`generic-graph.js` Dijkstra to a single-source traversal with a per-source `TraversalContext` cache so canonical-name lookups don't redo full-graph traversals.
- **Why:** Repeated per-target shortest-path queries during `mapNodeModules()` graph finalization were a hotspot for Lavamoat-scale graphs.
- **Themes:** compartment-mapper, performance
- **Status:** merged

## Description

This improves performance of finding the canonical name for a `Node` in a `Graph` dramatically
by computing all paths up-front and retrieving data from a cache of `TraversalContext` objects.

## Pull request overview

This PR improves canonical-name (shortest path) computation performance in `@endo/compartment-mapper` by caching Dijkstra traversal results per source node, avoiding repeated full-graph traversals during `mapNodeModules()` graph finalization.

**Changes:**
- Refactors Dijkstra to compute single-source shortest paths to all reachable nodes (removing the per-target parameter).
- Adds a per-source traversal-context cache in `makeShortestPath()` to reuse computed shortest-path data across repeated queries.
- Adds a changeset for a patch release noting the performance improvement.
