## Summary

- **What:** Drops `http-server` (and its transitive dep on the compromised `colors` package) from the SES demo `package.json`, switching the demo runner to `python3 -m http.server`.
- **Why:** The `colors` 1.4.x compromise affected anything depending on `http-server`/`node-static`; using a stock Python server is simpler and avoids the dependency.
- **Themes:** security, ecosystem-compat, chore
- **Status:** merged

## Description

The compromised `colors` package is pervasive enough that both `http-server` and `node-static` depend upon it. I’m comfortable just saying informally that you need to run `python3 -m http.server` for the demo.
