## Summary

- **What:** Adds `endo ping` and `endo log` subcommands to `@endo/cli` (with a corresponding ping responder in the daemon); `log` shells out to `tail`/`tail -f` over the user agent's log file.
- **Themes:** cli, daemon
- **Status:** merged

## Description

While fiddling with endo, these subcommands were useful. `ping` performs a trivial healthcheck, confirming that the daemon is running and connected to its named pipe or UNIX domain socket. `log` shells out to `tail` or `tail -f` for the user agent’s log file.
