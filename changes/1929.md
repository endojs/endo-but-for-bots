## Summary

- **What:** Moves the new `no-optional-chaining`/`no-nullish-coalescing` lint rule from `@endo/eslint-plugin`'s `recommended` config to the `internal` config (used only inside Endo) and bumps severity to `error`.
- **Why:** Downstream consumers like agoric-sdk picked up the rule from `recommended` and got noise; the rule should only fire inside Endo.
- **Themes:** tooling, ci, ecosystem-compat
- **Status:** merged

## Description

## Description

The new rule was enabled for the `recommended` config, so it was adopted in other repos such as agoric-sdk where is was only noise.

This moves it to the `internal` config used only by this repo. It also increases severity to `error` so that such usage will fail CI.

Incidentally, it makes `lint:eslint` consistent across packages (which I used to verify that they all still pass).
