## Summary

- **What:** Removes `Object.prototype.constructor` from `ses`'s default override-mistake enablements list, leaving it as a normal data property.
- **Why:** Fixes #477 and agoric-sdk#2324; unblocked once acorn upgrade landed (#588).
- **Themes:** ses-lockdown, ecosystem-compat
- **Status:** merged

## Description

Fixes https://github.com/Agoric/agoric-sdk/issues/2324
Fixes https://github.com/Agoric/SES-shim/issues/477

To enable `Object.prototype.constructor` to be overridden by assignment, we needed to make it into an accessor property. However, this confused the Node console as explained at https://github.com/Agoric/agoric-sdk/issues/2324 . But not doing so had been blocked by our dependency on acorn 7 which performs such an assignment. That dependency has now been fixed by 
https://github.com/Agoric/SES-shim/pull/588
and
https://github.com/Agoric/agoric-sdk/pull/2549
so we can proceed.
