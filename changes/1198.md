- **Themes:** ses-lockdown

## Description

For some scripts I was writing, I needed to write my own `lockdown.js` to do:

```js
import { lockdown } from '@endo/lockdown';
import './pre-remoting.js';

const options = {
  overrideTaming: 'severe',
  stackFiltering: 'verbose',
  errorTaming: 'unsafe',
};
lockdown(options);
```

This combination of options proved extremely useful for locking down one-off scripts with pervasive override mistakes, and that have no need to protect themselves against error stacks.

So, I created `@endo/init/legacy.js`.

## Node bug

