## Summary

- **What:** Breaking change in `@endo/compartment-mapper`: archive creation now requires the caller to pass a modules record listing exit dependencies that the importer must provide.
- **Why:** Makes the host-vs-archive boundary explicit instead of letting unsatisfied imports flow through silently.
- **Themes:** compartment-mapper, bundle-source
- **Status:** merged

## Description

Upon creating a new archive, the user will now be required to provide a
modules record (with meaningless values) to denote what dependencies are
expected to be provided by the importer.
