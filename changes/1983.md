## Description

## Description

`makeLRUCacheMap` is only _used_ by the SES error system, but is not really specific to it. It should eventually be an endo export, possibly in its own package (just not in `common`, which itself depends upon `ses`), but this PR just promotes it up one level into an easily-movable file for when that time comes.

### Security Considerations

This code is depended upon by SES assert code, and therefore cannot itself assume a hardened environment. All of the existing commentary and `freeze` calls were preserved.
