## Summary

- **What:** Adds a `@endo/eslint-plugin` rule disallowing `??` and `?.` operators (breaking) and rewrites `@endo/evasive-transform` and `@endo/bundle-source` to comply.
- **Why:** Agoric's load-generator test runs under `node -r esm`, which does not support nullish-coalescing or optional-chaining.
- **Themes:** tooling, ecosystem-compat, bundle-source
- **Status:** merged

## Description

Agoric’s load generator test uses `node -r esm` which doesn’t support the `??` nor `?.` operators.

This change introduces a lint rule to help us avoid this trip-fall and then ensures that existing packages pass the new rules.
