## Summary

- **What:** Adds JSDoc-only guidance in `@endo/patterns` explaining how to express fixed-length heterogeneous patterns over CopyRecord (struct-like), CopyArray (tuple-like), and CopyMap collections.
- **Why:** Until a rigorous patterns guide exists, this bandaid helps users find the right idioms for fixed-shape collection patterns.
- **Themes:** patterns, docs
- **Status:** merged

## Description

Until we have a rigorous treatment on the usage of patterns, this adds a bandaid to the code itself so anyone looking for how to make a pattern for a struct-like CopyRecord, tuple-like CopyArray, or fixed-length heterogeneous CopyMap will find their way.
