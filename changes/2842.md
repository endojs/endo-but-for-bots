This adds some types to `src/compartment.js` which were missing; specifically it creates a type for the bag of private fields associated with a `Compartment` via the `privateFields` `WeakMap`.

I've attempted to infer the types, but I am probably wrong in a place or two. I do not know which of these private fields are _required_ vs which are _optional_ (except for a couple obvious ones).

I also removed a triple-slash directive that was no longer necessary (afaict).
