## Description

Replaces #1627 

Starting with Node 16.9, `Object.hasOwn` is supported and does what our hand rolled `hasOwnPropertyOf` or `objectHasOwnProperty` did. This PR changes all uses to use `hasOwn` instead. However, for the sake of compat, it only deprecates the old exports. It does not delete them.

Reviewers, `objectHasOwnProperty` is not exported from ses. Should I delete it instead of deprecating it?

### @ljharb (NONE) — 2025-12-30T16:20:58Z

Note that this was a breaking change, released in a minor version. Since the `ses` package does not have an `engines` declaration, it implicitly supports every node engine, including node < 16.9.

The appropriate path here to comply with semver would be to revert this change, release it as a v1, and then (if desired) restore this change and publish it as a v2.
