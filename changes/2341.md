## Description

`deeplyFulfilled` has no dependence on concepts introduced by the @endo/marshal layer. This PR moves it to the @endo/pass-style layer, whose concepts it is directly about. See #1687 for other possible motives to do this.

For compat, this PR still has @endo/marshal reexport it, but marked as a deprecated reexport, advising importers to import from @endo/pass-style instead. Thus, this PR should count as a pure refactor which cannot break any old code.
