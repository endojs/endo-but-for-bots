## Summary

- **What:** Reimplements `uncurryThis` in `@endo/ses` using `Function.prototype.bind` (2x faster on v8 JIT, 1.5x jitless, 1.3x xsnap), fixes its TS type definition, and along the way fixes an unhandled-rejection logging bug uncovered by the corrected types.
- **Why:** `uncurryThis` is on hot paths throughout SES, and the bind form is significantly faster across all measured engines.
- **Themes:** ses-lockdown, performance, types
- **Status:** merged

## Description

From micro benchmarks, it looks like the bind form is 2x on v8 JIT, 1.5x on v8 jitless, and 1.3x on xsnap.

While looking at this I found a bug in the type definition, which when fixing, uncovered a couple real bugs (including one in the unhandled rejection logic).
