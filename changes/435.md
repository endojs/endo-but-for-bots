## Summary

- **What:** Stops URL-encoding compartment and path components when writing `endo` archives so `compartmap.json` locations match the actual zip entries (at the price of ambiguity for path components containing special symbols).
- **Themes:** bundle-source, compartment-mapper
- **Status:** merged

## Description

This broke the correspondence between locations in compartmap.json and what actually existed in a zip file. The cost of this change is the possibility of ambiguity for some special symbols in path components.
