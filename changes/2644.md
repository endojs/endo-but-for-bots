## Summary

- **What:** Widen `@endo/ses` `Compartment` `globalThis` and constructor `globals` parameter types from string-keyed to `Record<PropertyKey, any>` to allow Symbol keys.
- **Themes:** ses-lockdown, compartments, types
- **Status:** merged

## Description

`globalThis` can contain `Symbol` keys, so it is more correctly typed as `Record<PropertyKey, any>`.

This also widens the type of the `globals` parameter in the `Compartment` constructor.
