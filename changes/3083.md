## Description

There was some confusion recently about the API of `BundleCache`. This adds docs for it.

It also adds tests coverage, fixes up types and some runtime cleanup.

The new tests fail under Node 18 because it defaults to CJS for `.js` files. ~Since that version is past EOL this also removes it from CI matrix. And while searching it unpins `node-version` from jobs which aren't meant to test release compatibility (and should always work with latest default Node version).~ This provides a package.json and defers CI changes to https://github.com/endojs/endo/pull/3084
