## Summary

- **What:** Tolerates symbol-keyed property names in `ses` diagnostic text by wrapping interpolation in `String(prop)` instead of `${prop}`.
- **Why:** Symbols throw under template interpolation; agoric-sdk#2094 hit this.
- **Themes:** ses-lockdown, errors
- **Status:** merged

## Description

If the value of `prop` is a symbol `${prop}` throws whereas `${String(prop)}` produces a pleasing diagnostic. Should only be used to generate diagnostic text since the stringified from of a symbol is a valid string name for a property.

See https://github.com/Agoric/agoric-sdk/pull/2094
