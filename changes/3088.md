## Description

## Summary

- Adds three new message types (`eval-request`, `definition`, `form-request`) to the daemon mail system for capability-separated code evaluation
- Guests can propose code via `define()` (preferred) or `requestEvaluation()`, and hosts approve/bind capabilities via `endow()` or `approveEvaluation()`
- Adds `form()` / `respondForm()` for structured data exchange between agents
- Guests can persist passable values with `storeValue()` (backed by `formulateMarshalValue`)
- Adds the `llamadrome` package: an LLM agent (Anthropic + Ollama backends) that runs as an Endo guest with tool-calling, conversation persistence, and restart recovery
- Adds 5 new CLI commands: `define`, `endow`, `form`, `approve-eval`, `respond-form`
