## Summary

- **What:** Breaking change moving `@endo/compartment-mapper` entry modules (`import`, `archive`, `import-archive`) to the package root, dropping the Rollup CJS build to lean on RESM/NESM interop.
- **Why:** Lets agoric-sdk consume each subentry directly while still supporting RESM-importing-NESM.
- **Themes:** compartment-mapper, ecosystem-compat
- **Status:** merged

## Description

This change allows for RESM/NESM compatibility, after @michaelfig’s Agoric SDK bypass that allows RESM to import NESM, such that a dependee can extract the `import`, `archive`, or `import-archive` submodules. This sacrifices CommonJS support since the entry point module must be named in `main`. For consistency, I moved the entry modules all to the top level. I removed the Rollup build since it doesn’t carry its weight without the CommonJS story.
