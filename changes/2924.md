## Description

This PR modernizes the ESLint configuration structure in the `@endo/eslint-plugin` package while maintaining backward compatibility with existing package configurations.

## Key Changes

**ESLint Plugin Config Modernization**
- Updated all configuration files in `packages/eslint-plugin/lib/configs/` to use modern ESLint patterns
- Maintained legacy format for compatibility with existing `eslintConfig` sections in package.json files
- Preserved all SES/Endo-specific globals and custom rules from the original configurations
- Updated TypeScript integration and dynamic configuration handling

**Configuration Files Updated**
- `recommended.js` - Core SES globals and fundamental rules
- `style.js` - Airbnb base + JSDoc + Prettier integration with TypeScript overrides
- `imports.js` - ES module import/export rules
- `strict.js` - Combined strict configuration
- `ses.js` - SES-specific restricted globals with test file exceptions
- `internal.js` - Complex TypeScript configuration with dynamic rule handling
- `daemon.js` - Deprecated configuration (maintained for compatibility)
- `recommended-requiring-type-checking.js` - TypeScript-aware rule extensions

**Compatibility Preserved**
- All existing `eslintConfig` sections in package.json files continue to work unchanged
- No breaking changes to existing linting workflows
- Maintained all original rule configurations and exceptions
- Preserved ignore patterns and file-specific overrides

The modernized configurations provide a foundation for future ESLint upgrades while ensuring zero disruption to the current development workflow.

Addresses #2682.
