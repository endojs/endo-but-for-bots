## Summary

- **What:** Makes the `pid` argument added to `@endo/bundle-source`'s cache maker optional, defaulting to a crypto-random number; pins Node 20 in `test-async-hooks` to 20.5 to dodge a Babel error.
- **Why:** The previous required `pid` was an accidental breaking change; the random default is also better behaved when one process has multiple caches.
- **Themes:** bundle-source, ecosystem-compat, ci
- **Status:** merged

## Description

In the most recent Endo release, I added a required `pid` argument to the bundle source cache maker, which is a breaking change. This change reverses that mistake by making the argument optional and using a large crypto-random number instead. It transpires that this new, default behavior is better than passing the `pid` for a process with more than one cache.
