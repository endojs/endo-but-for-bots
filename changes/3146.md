## Description

## 🚀 New Feature

### Problem
The current pet store implementation needs to be more resilient against naming collisions and unauthorized access when AI agents attempt to resolve pet names.

**Severity**: `medium`
**File**: `packages/daemon/src/pet-store.js`

### Solution
Add validation logic to `writePet` and `readPet` to ensure that pet names follow a strict naming convention (e.g., alphanumeric and hyphens) and implement a more robust locking mechanism to prevent race conditions during concurrent AI requests.
