## Summary

- **What:** Draft introducing async-capable attenuator makers in `@endo/compartment-mapper` for module and globals attenuation, plus `exitModuleImportHook` for dynamic exit modules with attenuation.
- **Why:** Today's policy attenuators are sync-only; MetaMask's use cases want async attenuators (e.g., loading remote policy state) and a two-step "maker" shape.
- **Themes:** compartment-mapper, security
- **Status:** draft

## Description

Currently attenuation implemented in policy only allows for synchronous attenuators. 

This PR is meant as an implementation draft for when we decide we want the async capable attenuators.

Globals attenuator could be asynchronous right away. dfefining an attenuator maker for it and making it two-step is only considedred for consistency with the module attenuator, but it's unlikely they'd end up with any similarity in arguments input anyway.
