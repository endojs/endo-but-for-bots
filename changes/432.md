## Summary

- **What:** Lets `ses` `importHook` return a record whose specifier differs from the requested specifier (the alias becomes the canonical referrer for transitive imports), enabling Node-style `name` → `name/index.js` redirects.
- **Themes:** ses-lockdown, compartments
- **Status:** merged

## Description

This change enables importHook to return a record for a module that has a different specifier than the requested module specifier.  This enables the Node.js pattern of redirecting `name` to `name/index.js` and respecting the latter name as the referrer for its own imports.
