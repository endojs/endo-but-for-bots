## Summary

- **What:** Restores `var` declarations (rather than `const`) in `ses` global type definitions so `globalThis.assert` and friends are picked up by TypeScript's ambient-globals lookup.
- **Why:** A previous eslint-driven edit changed `var` to `const` in a `.d.ts`, which broke ambient global typing.
- **Themes:** ses-lockdown, types
- **Status:** merged

## Description

Evidently, in a recent change to appease eslint, SES stopped exporting a type for globalThis.assert et al.
