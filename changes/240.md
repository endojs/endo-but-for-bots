## Description

Fixes #237 

The constructor and prototype structure of the regexp taming was wrong in many ways, including leakage of the `unsafeRegExp` constructor, which is a security hole. I first wrote the new test cases in this PR to demonstrate six cases that fail to work with the old structure. All those cases pass now.

On the way, I discovered https://github.com/Agoric/SES-shim/issues/239 which I'll fix in a separate PR
