## Summary

- **What:** In `@endo/marshal`, encodes capData with one level of JSON instead of nested-string body, using `lastIndexOf` to split (similar to #1558) and adding fastcheck property tests.
- **Why:** Senders pay by the byte and double-encoding bloats payloads (Agoric/agoric-sdk#7999); reviewers prefer to first split encoding/serialization (#1478) and not rely on undocumented body-format invariants.
- **Themes:** marshal, performance
- **Status:** open / blocked on encoder/serializer split discussion

## Description
