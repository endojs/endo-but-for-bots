## Summary

- **What:** Adds an `SES_VIEW_ASSERT_ERROR` env-option (values `breakpoint`, `log`, `none`) to `ses`'s `makeError` so assertion failures can drop into the debugger or log on construction.
- **Why:** Diagnosing assertion failures inside hardened code is hard; this gives developers a targeted hook.
- **Themes:** ses-lockdown, errors
- **Status:** draft
