## Summary

- **What:** Lets the SES shim use the start compartment's `globalThis.harden` (renamed `safeHarden`) when present, rather than always using the shim's implementation.
- **Why:** Hosts like Moddable XS can supply a faster native `harden`; SES picks it up automatically.
- **Themes:** ses-lockdown, performance, ecosystem-compat
- **Status:** merged

## Description

Allows the start compartment to provide `globalThis.harden` to override the `harden` used by the SES shim.
This enables some hosts (like Moddable's XS) to provide their own (likely more performant) `harden` implementations.
