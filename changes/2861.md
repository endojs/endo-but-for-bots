## Summary

- **What:** Makes `@endo/pass-style` work when running on older `ses` releases that lack `ArrayBuffer.prototype.transferToImmutable`, by feature-detecting it before treating buffers as `byteArray`.
- **Why:** Newly-published `pass-style` was breaking on hosts running pre-1.13.0 `ses`.
- **Themes:** pass-style, ecosystem-compat
- **Status:** merged

## Description

The most recent releases of ses and pass-style introduce support for immutable ArrayBuffer with a pass-style of “byteArray” in anticipation of the upcoming JavaScript standard. Although versions of pass-style and ses that were published together work together, pass-style on older versions of ses on platforms that predate immutable ArrayBuffer (virtually all), pass-style does not tolerate the non-existence of immutable `ArrayBuffer.prototype.transferToImmutable` whether shim or native. This change makes pass-style suitable on all previously supported platforms.

https://github.com/endojs/endo/releases/tag/ses%401.13.0
