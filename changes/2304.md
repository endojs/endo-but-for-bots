## Summary

- **What:** Adds custom parser support to `@endo/compartment-mapper`, including a new `parsers` option on entry points and an `options` field on `PackagePolicy`; built-in parsers cannot be overridden (closes #2303).
- **Why:** Enables third-party language plugins (e.g., for non-JS sources) while keeping policy/integrity guarantees intact.
- **Themes:** compartment-mapper, ecosystem-compat, security
- **Status:** merged

## Description

This PR adds custom parser support as discussed in #2303. To support the feature:

- A new prop `options` was added to the `PackagePolicy` type.
- Parsers now optionally accept `compartmentDescriptor` objects, so that parsers can enforce policy
