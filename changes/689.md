## Summary

- **What:** Changes `ses-integration-test` to wait for a page error or the TAP footer instead of just the page title to stop CI flakes.
- **Why:** Refs #688 — title render fired before the in-page tests had emitted results.
- **Themes:** tests, ci, ses-lockdown
- **Status:** merged

## Description

The SES integration tests have begun to flap: about one in four CI runs fail because the integration test failed for one Node.js version or the other. This appears to be because the test runs until the page title renders, which is sometimes before the tests produce any results. This changes the test to run until a page error is emitted or the TAP footer gets written.

Refs #688
