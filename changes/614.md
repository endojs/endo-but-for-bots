## Summary

- **What:** Adds known browser/XS-specific extensions to `ses` `whitelist.js` with `false` so lockdown removes them silently rather than logging a surprise.
- **Why:** Reduces noise from #612-style surprise logs across Chrome, Firefox, Safari, and XS.
- **Themes:** ses-lockdown, ecosystem-compat
- **Status:** merged

## Description

Entering these properties into whitelist.js with a `false` setting, like omitting them, causes them to be removed. But listing them explicitly records that we're not surprised by seeing them, so `lockdown` removes them silently. If we see a property that does not appear on the whitelist at all, `lockdown` logs a record of that so we can react to the surprise. https://github.com/endojs/endo/issues/612 nicely demonstrates how useful that feedback is.

This PR is a result of testing https://ses-demo.netlify.app/demos/console/ on a variety of browsers, plus recording what we already know about XS. Because I am on a Mac, I have not tested Edge. If someone could and post the console output, that would be appreciated.
