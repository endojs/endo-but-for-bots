## Summary

- **What:** Reworks `@endo/captp` GC: adds `CTP_DROP.decRefs` with in-transit `exportID` ref counts, splits `slotToVal` into `slotToImported` (strong) and `slotToExported` (weak with finalizers), removes unnecessary `async` to better separate CapTP errors from userspace errors, and disables GC by default.
- **Why:** Fixes races in distributed reference dropping; ships behind a flag because distributed GC needs more soak time.
- **Themes:** captp, eventual-send, errors
- **Status:** merged

## Description

- Uses in-transit `exportID` reference counts to prevent races when dropping references
- Split the `slotToVal` map into `slotToImported`(strong)  and `slotToExported` (weak values with finalizers)
- Remove `async` methods wherever possible to better distinguish and propagate CapTP errors vs. userspace errors
