## Summary

- **What:** Teaches `@endo/compartment-mapper`'s CJS shim to use a top-level `return` value as the module's exports when present (falling back to `module.exports` otherwise).
- **Why:** A handful of npm CJS packages use the obscure top-level-return idiom to export.
- **Themes:** compartment-mapper, ecosystem-compat
- **Status:** closed-unmerged

## Description

## Description
One of the rarely used ways to export from a CJS module is to `return` a reference instead of setting `module.exports` to that reference. This PR adds support for that behavior and a tiny fixture in tests to ensure it works in all scenarios.
