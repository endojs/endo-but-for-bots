## Summary

- **What:** Patches Node's `AsyncLocalStorage` from `@endo/init` so it stops adding symbol expando properties (`[kResourceStore]`) to promises, keeping them compatible with `@endo/pass-style`'s `safePromise` check; adds Node 20 to the async-hooks CI matrix.
- **Why:** Fixes #1657 — `harden`-ing a promise would otherwise harden any AsyncLocalStorage store hung off it via the expando.
- **Themes:** pass-style, ses-lockdown, ecosystem-compat, ci
- **Status:** merged

## Description

Fixes #1657 

Monkey patch the `AsyncLocalStorage` implementation to rewrite the handling of stores, replacing the use of symbol expando properties on promises with a WeakMap per instance.

`@endo/pass-style` and more specifically the `safePromise` check asserts that no extra own keys exist on promise instances. Furthermore hardening a promise would also harden any store object added as expando to promise instances.
