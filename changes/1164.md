## Summary

- **What:** Fix in `@endo/eventual-send` `handle` so that rejecting with a rejected-promise reason doesn't accidentally adopt the inner rejection as an unhandled rejection of the outer.
- **Themes:** eventual-send
- **Status:** closed-unmerged

## Description

If a result is rejected with a rejected promise as reason, `handle` would harden the promise, and return it, causing it to be adopted, and actually becoming the unhandled rejection we were trying to avoid in the first place.
