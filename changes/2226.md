## Summary

- **What:** Adds an `E(host).storeValue(value, name)` API to `@endo/daemon` that marshals copy-data and remotables backed by formula identifiers; settles on `marshal` as the new formula type (not `value` or `data`).
- **Why:** Lets clients durably store passable values composed of pet-named references; built on `@endo/marshal`.
- **Themes:** daemon, marshal
- **Status:** merged

## Description

This change adds a `E(host).storeValue(value, name)` API allowing us to store passable data, provided it consists of copy-data and references with known formulas.
