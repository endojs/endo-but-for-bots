## Summary

- **What:** Adds an `esbench` microbenchmark CLI under `scripts/` that drives `eshost` to measure JS snippet performance across multiple ECMAScript implementations.
- **Why:** Gives Endo a way to measure perf hotspots like `passStyleOf` across XS, V8, etc.
- **Themes:** tooling, performance
- **Status:** open / under review (reviewer asked for a pivot to a ses-ava-like in-process benchmark framework rather than this CLI/separate-process shape)

## Description

Measure performance of code snippets in multiple ECMAScript implementations using the `eshost` CLI.
