## Summary

- **What:** Drops `@endo/ses-ava`'s Rollup-built CJS/UMD outputs in favor of single-entry `type: module` ESM that works under both native ESM and the patched `esm` loader, plus a docs fix.
- **Why:** Mirrors the entry-point rearrangement in #732; the patched `esm` now bridges to native ESM packages.
- **Themes:** tests, ecosystem-compat, docs
- **Status:** merged

## Description

These two commits address needs for ses-ava to straddle Node.js ESM support and `node -r esm` emulation of ESM support on the Node.js CommonJS loader. Our patched version of `esm` now allows us to import from the underlying CommonJS loader, which allows packages to use a single entry point and `type: module` and serve both native and emulated ESM support. However, we cannot use the trick of using Rollup to compile to CommonJS. This change sacrifices downward compatibility with CommonJS in favor of straddling RESM/NESM.

This also includes a usage documentation fix.
