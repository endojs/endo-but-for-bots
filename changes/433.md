## Summary

- **What:** Rewrites `endo`'s compartment assembler atop `ses`'s new `moduleMapHook` so cross-compartment cycles work; turns the previously-recursive `assemble` into a flat, lazy build.
- **Themes:** compartment-mapper, ecosystem-compat
- **Status:** merged

## Description

Refactors Endo’s compartment assembler using the new `Compartment` `moduleMapHook` such that compartments may have mutual dependencies, as evidence suggests exists in practice. This has the consequence of making `assemble` flat and lazy instead of recursive.
