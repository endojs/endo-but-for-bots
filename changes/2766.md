## Summary

- **What:** Adds a new `@endo/ocapn` package with codecs for OCapN messages, Passable types, ordered-key structs, tagged values, and float64; subsumes `@endo/syrup` into it.
- **Why:** Endo doesn't intend to support generic syrup parsing — only the OCapN-shaped subset — so the package boundary is being moved.
- **Themes:** ocapn, marshal, pass-style
- **Status:** merged

## Description

- Introduces new `ocapn` package with initial codecs for OCapN messages and Passable types
- subsumes `syrup` package into `ocapn` as we don't intend to support generic syrup parsing
