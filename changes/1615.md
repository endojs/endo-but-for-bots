Per this feedback, I took a run at making these descriptions much more concise at the end of the `endo` branch. The spike continues but I’ve left these PRs behind.

```
  open [options] <name> [filePath]                      opens a web page (weblet)
  run [options] [<file>] [<args>...]                    runs a program (runlet)
  make [options] [file]                                 make a plugin or a worker caplet (worklet)
  inbox [options]                                       read messages
  request [options] <informal-description>              ask someone for something
  resolve [options] <request-number> <resolution-name>  grant a request
  reject [options] <request-number> [message]           deny a request
  send [options] <party> <messag>                       send a message with @named-values @for-you:from-me
  adopt [options] <message-number> <name-in-message>    accept a @value from a message
  dismiss [options] <message-number>                    delete a message
  list [options]                                        show names
  remove [options] [names...]                           forget a named value
  rename [options] <from> <to>                          change the name for a value
  show [options] <name>                                 prints the named value
  follow [options] <name>                               subscribe to a stream of values
  cat [options] <name>                                  dumps a blob
  store [options] <path>                                stores a blob
  eval [options] <source> [names...]                    creates a value
  spawn [options] [names...]                            creates a worker
  bundle [options] <application-path>                   stores a program
  mkhost [options] <name>                               makes a separate mailbox and storage for you
  mkguest [options] <name>                              makes a mailbox and storage for a guest (peer or program)
  where                                                 prints paths for state, logs, caches, socket, pids
  start                                                 start the endo daemon
  stop                                                  stop the endo daemon
  restart                                               stop and start the daemon
  clean                                                 erases ephemeral state
  reset                                                 erases persistent state and restarts if running
  log [options]                                         writes out the daemon log, optionally following updates
  ping                                                  prints ok if the daemon is responsive
  help [command]                                        display help for command
```
