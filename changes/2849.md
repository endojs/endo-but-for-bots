## Summary

- **What:** Tightens `@endo/eventual-send` types so eventual-call results are always `Promise`, introduces `EResult`/`EAwaitedResult` to map remotables to their "brand" type for callers, removes `Remote`/`ERemote` helper types, and casts a few `any`s in `@endo/daemon`.
- **Why:** Helps agoric-sdk type-check eventual-send call sites without depending on accidental presence/local-remotable conflations.
- **Themes:** eventual-send, captp, types
- **Status:** merged

## Description

Refs: https://github.com/Agoric/agoric-sdk/pull/11454

## Description

Narrows some eventual-send types. In particular, ensure that the result of an eventual call is a promise.

Add an `EResult` type which in the future can represent the return type of an eventual send call where remotables are mapped as necessary to their "brand" type only to avoid the caller from relying on what may otherwise look like a local remotable instead of a presence.

This mapping is implemented in the `EAwaitedResult` type for explicit usages, but not yet used in the type of `EResult` itself as it breaks too many consumers of `E` that rely on the currently "incorrect" typing.
