## Summary

- **What:** Follow-up to #407 — adds an existence check before `newIntrinsics[intrinsicName] = globalObject[globalName]` so missing primordials (e.g. `StaticModuleRecord` absent from the global) don't get materialized as `undefined` entries.
- **Themes:** ses-lockdown, ecosystem-compat
- **Status:** merged

## Description

Follow up to #407

Because `StaticModuleRecord` was listed in the whitelist's `universalPropertyNames` but was absence from the global, the old

```js
newIntrinsics[intrinsicName] = globalObject[globalName];
```
was creating a property on `newIntrinsics` named `StaticModuleRecord` with value `undefined`. This PR adds a check so that absent properties on `globalObject` skip the above assignment.
