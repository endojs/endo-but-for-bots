## Summary

- **What:** Breaking change in `ses`: `lockdown` may only be called once, returns `undefined`, and throws on subsequent calls instead of returning a boolean indicating whether it was effective.
- **Why:** Fixes #814 — multi-lockdown semantics were a hazard and complicated the pipeline; harden-intrinsics is now deferred and lockdown closures are released after they run.
- **Themes:** ses-lockdown, security
- **Status:** merged

## Description

*BREAKING CHANGE*: Lockdown can no longer be called more than once.  Lockdown no longer returns a boolean to indicate whether it was effective (true) or redundant (false). Instead, Lockdown will return undefined for its first invocation or throw an error otherwise.

Fixes #814
