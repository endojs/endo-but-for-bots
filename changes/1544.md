## Summary

- **What:** Splits `@endo/bundle-source` into a reusable `cache.js` library and a `tool.js` CLI entrypoint, tightens power use in `cache.js`, and adds filesystem-based locking to prevent concurrent bundling collisions; switches to `jessie.js` `asyncGenerate`.
- **Why:** Lets other packages import the bundle cache directly and prevents clobbering during parallel AVA test runs.
- **Themes:** bundle-source, tooling, tests
- **Status:** merged

## Description

Please review commit-by-commit to avoid changes caused only by splitting the files.

- Make `@endo/bundle-source/cache.js` importable by other packages that want a bundle cache
- Separate the `bundle-source` script from the `cache.js` library, to make it clearer as a `tool.js` entrypoint
- Add filesystem-based locking to prevent bundling update collisions (seen when running AVA tests in parallel)
