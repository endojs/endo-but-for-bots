## Summary

- **What:** Lets `importHook` in `@endo/ses` `module-load` return a `RedirectStaticModuleInterface` alias record without a backing record, so `module-load` will re-attempt the import (potentially via `moduleMapHook`).
- **Why:** Needed by compartment-mapper changes that resolve the `browser` field through aliasing other modules.
- **Themes:** ses-lockdown, compartments, compartment-mapper
- **Status:** merged

## Description

allow `importHook` to return an alias record that `ses/src/module-load.js` can attempt to import
this allows `importHook` to resolve to something that may be provided by a different part of the import phase, like the `moduleMapHook`
