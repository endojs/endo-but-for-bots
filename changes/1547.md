## Summary

- **What:** Adds default type parameters to `@endo/patterns` copy collection types so `CopyBag` is usable without writing `CopyBag<Key>`.
- **Why:** Lets agoric-sdk drop redundant alias names like `CopyBagValue` (Agoric/agoric-sdk#7363, #7352).
- **Themes:** patterns, types, ecosystem-compat
- **Status:** merged

## Description

Enables us to say, for example, `CopyBag` rather than `CopyBag<Key>`, which in turn lets agoric-sdk delete unnecessary names like `CopyBagValue`.

Coordinated with change to agoric-sdk at https://github.com/Agoric/agoric-sdk/pull/7363

Will help https://github.com/Agoric/agoric-sdk/pull/7352
