## Summary

- **What:** Adds robustness features to `@endo/captp`: WeakRef/FinalizationRegistry GC of remote refs, `nearOptions`/`farOptions` on `makeLoopback`, `isOnlyLocal`/`isOnlyNear`/`isOnlyFar` predicates, `importHook`/`exportHook` for in-transit interception, and a `.then` reentrancy guard.
- **Themes:** captp, security, performance
- **Status:** merged

## Description

Added some new features:

- implement WeakRef/FinalizationRegistry-based garbage collection (refactoring for this tightened up the implementation considerably)
- allow optional `nearOptions` and `farOptions` for `makeLoopback`
- expose `isOnlyLocal(specimen)` to see if a passable specimen contains any nonlocal promises/presences
- add `importHook(val, slot)` and `exportHook(val, slot)` to allow interception of vals that are being imported/exported.  This allows warning about (or preventing) in-transit object references that may be severed if the client exits
