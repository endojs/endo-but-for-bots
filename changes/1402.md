### @gibson042 — APPROVED — 2023-01-27T17:04:18Z

This PR is implicitly defining **CapData** as a record structure that currently encompasses a `body` string and a `slots` array, in which the encoding of `body` is implicitly either "_Smallcaps_"[^1] if the first character is "#" or [_unnamed original encoding_][^2] otherwise. That works for me, and we can propagate those definitions in followup changes.

Thanks @turadg!

[^1]: [JSON text](https://www.rfc-editor.org/rfc/rfc8259#section-2) in which arbitrary [pass-by-copy](https://docs.agoric.com/guides/js-programming/far.html#pass-styles-and-harden) source data has been made representable mostly by translation of JSON-incompatible values into "#…" strings
[^2]: [JSON text](https://www.rfc-editor.org/rfc/rfc8259#section-2) in which arbitrary [pass-by-copy](https://docs.agoric.com/guides/js-programming/far.html#pass-styles-and-harden) source data has been made representable mostly by translation of JSON-incompatible values into objects with `@qclass` members
