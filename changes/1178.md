## Summary

- **What:** Implements an `unhandledRejectionTrapping` option in `ses` (XS-style: WeakRef + FinalizationRegistry tracking of unhandled rejections) and audits `@endo/eventual-send` to suppress spurious unhandled rejections when only `then` (no `catch`) is attached.
- **Why:** Closes #1164 — verbose, accurate unhandled-rejection reports without false positives from late-attached catches.
- **Themes:** ses-lockdown, eventual-send, errors
- **Status:** merged

## Description

Closes: #1164

# XS approach to unhandled rejections

This PR was inspired by the unhandled rejection support in the XS engine.  Their trick is to keep a `Map<WeakRef<Promise>, reason>` for the rejections that were not handled synchronously.  Then, the map entry is removed if the rejection is handled before it is GCed or the process exits.

We accomplish the same behaviour with a FinalizationRegistry and a combination of a weak and strong map.  That removes the need for periodic scanning of WeakRefs.

# Impact on eventual-send

I also audited the eventual-send implementation to fix the times when a promise had a then handler attached (but no catch), which was the main source of unnecessary unhandled rejections.

The combination of these should provide more verbose errors for actual unhandled rejections when using SES, as well as minimising the amount of noise due to handlers that were attached anytime before the promise was GCed.

# Demo

Here is a demonstration of running under Node:

```js
/* global setTimeout */
import '@endo/init';

const test = async () => {
  const f = Promise.reject(Error('f'));
  const g = Promise.reject(Error('g'));
  // eslint-disable-next-line no-unused-vars
  const h = Promise.reject(Error('h'));

  f.catch(reason => console.log('@@@ handled', `${reason}`));

  console.log('@@@ delay a little bit');
  await new Promise(resolve => setTimeout(resolve, 1500));
  console.log('@@@ delay done');

  g.catch(reason => console.log('@@@ handled', `${reason}`));
};

test();
```

```console
$ node test-unhandled.js

@@@ delay done

Error#1: h

  at test (packages/eventual-send/t.js:8:28)
  at packages/eventual-send/t.js:19:1
  at async Promise.all (index 0)
$
```
