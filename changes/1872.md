## Summary

- **What:** In `@endo/daemon` Node `makeFilePowers`, queues disk operations behind a mutex so concurrent in-memory updates are serialized to disk in order.
- **Why:** Avoid races when overlapping pet-store writes interleave on the filesystem.
- **Themes:** daemon
- **Status:** merged

## Description

use mutex to ensure serial file operations

all updates happen synchronously in memory
all disk operations are queued to ensure that the previous operation completed before continuing
