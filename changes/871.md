## Summary

- **What:** SES `lockdown` now reads each option's default from a corresponding `LOCKDOWN_*` environment variable (with `getEnvironmentOption`/`setEnvironmentOption` helpers), so deployers can flip `errorTrapping`, `domainTaming`, etc. without code changes.
- **Why:** Lets developers and CI configure SES behavior without rebuilding the application; @erights and @kriskowal agreed to factor out `getEnvironmentOption` for reuse outside SES.
- **Themes:** ses-lockdown, ecosystem-compat
- **Status:** merged
