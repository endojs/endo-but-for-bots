## Summary

- **What:** Adds `endo exec [...command]` so any subprocess inherits SES lockdown, respecting `ENDO_*_TAMING` env vars; intended as a wrapper for test runners (e.g. `endo exec mocha`).
- **Themes:** cli, ses-lockdown
- **Status:** merged

## Description

This change introduces an `endo exec [...command]` command. Any child process of the given command will run after SES lockdown. Each child `node` process will respect certain `ENDO_*_TAMING` environment variables. This is not water-tight, but is an initial pass at a tool we and others can use to wrap test commands, e.g., `endo exec mocha` instead of just `mocha` to run Mocha tests.
