## Summary

- **What:** Repairs CI so `lint:type` actually runs (`tsc -p` instead of `--build`), bumps Node 12 minimum to 12.22, drops Node 12.17, and pins all packages to TS `~4.2.3`; also fixes an `lp32` return-type issue.
- **Why:** Closes #1058 — type checks had been silently skipped in CI due to misconfigured `--build`; TS versions were drifting between root and packages.
- **Themes:** ci, types
- **Status:** merged

## Description

Run lint type checks with `-p` instead of `--build`. Closes #1058 
Fix a type issue that arose in `lp32`

Remove Node 12.17 from the CI matrix. Bump minimum node version to `12.22` as that will be the minimum version supported by the upcoming TS 4.5 change (see #1043)

Unify TypeScript to version `~4.2`. The base `package.json` was stuck on `4.0`, but other packages specified `^4.2.3` which resolved in `yarn.lock` to `4.5.5`. The intent was to have everyone use `4.2` so update base and all packages to `~4.2.3` which prevents picking a version with a different minor, but will pick up new patch version if needed.
