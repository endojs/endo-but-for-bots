## Description

This prepares new versions for release and includes an update for the release process.

The new release process is a variation on the notes in the Agoric SDK MAINTAINERS.md and retains the insights accumumulated in the prior Endo CONTRIBUTING.md where they are still relevant.

This reflects our recent shift to using `lerna` to publish all packages in bulk, and retains our practice of hand-written NEWS.md for user-facing release notes.
The process varies from the notes described in Agoric SDK by clarifying how to prepare a release for code review and avoids creating tags until after code review is complete.

The release process also omits some complications that are specific to Agoric SDK.

- chore: lerna version
- chore: Update release notes
- docs: Update release process
