## Description

I think I did well at the `lockdown` and `Compartment` globals, but am
less sure about how strictly you'd all like to type `harden` or
`StaticModuleRecord`.

I believe these types are at least nearly accurate enough to allow most
typescript projects to import `ses` without issues, but extra safety
could be added by adding specificity.

To import this into another module and test it, I used `yarn link` to connect them and added `"./node_modules/ses/src/ses.d.ts"` to my `tsconfig.json`'s `include` array. I _think_ there should be a way to not need that line, but for whatever reason I wasn't able to find the way around it. I'm slightly new to TS.
