## Summary

- **Themes:** security, tooling, chore

## Description

This updates `yarn.lock` to include newer versions of `acorn` and `minimist`, in an attempt to address the security alerts that github is flagging. I'm not confident that it will address all of them, but I want to see if it makes a dent at all.

Github is currently warning about three things:

* acorn in the top-level yarn.lock
* minimist in the top-level yarn.lock
* minimist in packages/make-simple-evaluate/yarn.lock

Github/dependabot filed a PR for `acorn`, however 1: the PR was landed already, 2: there are three distinct versions of `acorn` cited in our yarn.lock. 3: two of those versions were in the advisory as insecure, and 4: the PR only modified one of them. This PR modifies the other insecure one, in the hopes that dependabot will be satisfied

There were three distinct versions of `minimist` mentioned in yarn.lock. This PR bumps the highest-versioned mention to a secure version (1.2.5). The other two are very old, `mkdirp` is forcing an exact dependency on 0.0.8, while `optimist` depends on `~0.0.1` (which is satisfied by `0.0.10`). Everything older than `1.2.2` is marked as insecure, so I don't see an easy way to shed the insecure old versions.
