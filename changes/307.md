## Summary

- **What:** Removes all SES module exports and instead surfaces `lockdown`, `harden`, `Compartment`, and `ModuleStaticRecord` on `globalThis`, matching how a platform shim would introduce them.
- **Why:** Fixes #301.
- **Themes:** ses-lockdown, compartments
- **Status:** merged

## Description

Previously, SES exported `lockdown`. Calling `lockdown` introduces a global `harden`.

This change removes all exports and instead surfaces the same names on `globalThis`. That is, `lockdown`, `harden`, `Compartment`, and `ModuleStaticRecord` are all globals as they would be if they were introduced by the platform rather than a shim.

Fixes #301
