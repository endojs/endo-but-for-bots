## Summary

- **What:** Removes the deprecated `@agoric/harden` package's tombstone source from the repo, since `harden` is now folded into `make-hardener` which is folded into `ses`.
- **Why:** npm's deprecation notice already warns at install/registry time, so the in-repo tombstone is redundant.
- **Themes:** ses-lockdown, chore
- **Status:** merged

## Description

Harden has been deprecated for some time and the source was left as a tombstone. Npm deprecation provides prominent notifications both at install time and on the website so this tombstone is no longer necessary.

Harden is subsumed into Make Hardener, which is subsumed into SES since using makeHardener does not make sense outside the context of a SES environment.
