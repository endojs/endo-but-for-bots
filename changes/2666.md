## Description

We generally use names of the form `^([A-Z]\w*)I$`, i.e., identifiers beginning with a capital letter and ending with a lone capital "I", for interface guards. However there were some uses of the same form of name for typescript interfaces. Because interfaces and interface guards are adjacent concepts, this could be confusing. This PR fixes this for endo. The companion https://github.com/Agoric/agoric-sdk/pull/10751 fixes it for agoric-sdk. Because the endo names in question were not exported, there is clearly no dependency between these two PRs.
