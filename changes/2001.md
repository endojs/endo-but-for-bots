## Summary

- **What:** In `@endo/marshal`, replaces XS-expensive random string-character access with iterator-style access in the smallcaps decoder.
- **Why:** XS string indexing is O(n); decoding a representative CopyRecord goes 21% faster, an array of 10 copies ~100% faster, with no significant Node regression.
- **Themes:** marshal, performance, ecosystem-compat
- **Status:** merged

## Description

Ref #1982

## Description

Speeds up by 21% decoding a representation of the following CopyRecord:
```
{
  primitives: [undefined, null, true, false, 0, 1, 0n, 1n, "foo", Symbol.for("bar")],
  arrays: [[], [{}]],
  records: { empty: {}, singular: { array: [] } },
}
```
(and speeds up decoding a CopyArray containing 10 copies thereof by about 100%)

No significant effects in Node.js.
