## Summary

- **What:** Adds an alias map to the `@endo/compartment-mapper` bundler so import resolution can fast-forward through aliases to the real module.
- **Why:** Lets the bundler bootstrap larger systems (e.g., bundles that pull in `@endo/eventual-send`, `@endo/import-bundle`, `@endo/captp`).
- **Themes:** compartment-mapper, bundle-source
- **Status:** merged

## Description

The Compartment Map contains a bundler that is entirely sufficient for bundling SES proper. Since its original design, @naugtur expanded it to handle CommonJS. So, the missing feature that would make it suitable for bundling a larger bootstrapping system, say, one that could bootstrap eventual-send and import-bundle, was module aliases.

This change introduces an alias map, which fast-forwards every import resolution thru aliases to the concrete implementation of the imported module.
