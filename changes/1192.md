### @mhofman — CHANGES_REQUESTED — 2022-05-24T21:22:03Z

I don't believe this will work as-is. I think our approach should be:
- assume the object is not a proxy (later we can add a brand check as the first test)
- Check that the prototype is `Promise.prototype`
- Check that the object doesn't have own `then` or `constructor` props
- Only then check that the object is a native promise with `Promise.resolve(p) === p`, as that step can trigger any `constructor` or `then` getters, either own or on the prototype chain.

It's actually not strictly necessary to check that the object is frozen since after a proxy brand check, we know that no traps can be triggered while our code is on the stack, but we still should perform a frozen check since it'll guarantee that the promise won't add an own `then`/`constructor`, or change the proto chain, once our stack has unwound (I'd like to think about what it'd take to make `HandledPromise` not reliant on `lockdown` and frozen objects but that's another story).

The biggest complexity however is not the "safe promise" check, but first `Promise.resolve()` done before we even call this predicate. https://github.com/endojs/endo/blob/db2ac2c357522c26754a7e2d1fc882c0d21d1a1d/packages/eventual-send/src/handled-promise.js#L437
