## Summary

- **What:** Updates `@endo/import-bundle`'s inescapable Compartment-constructor wrapper to the new single-options-bag signature introduced by #2386, plus integration tests for inescapable globals.
- **Why:** The Compartment shape change broke the only known wrapper (`compartment-wrapper`), which inescapable globals depend on.
- **Themes:** ses-lockdown, compartments, compartment-mapper, ecosystem-compat
- **Status:** merged

## Description


## Description

Recent changes to align the Compartment constructor in SES with its XS counterpart changed the argument pattern and this broke the interface of all extant wrappers around the Compartment constructor, of which we only know of one. This change fixes that wrapper and restores continuity of compatibility.
