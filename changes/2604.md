## Summary

- **What:** Re-version `@endo/patterns` and `@endo/pass-style` back onto the 1.x train as 1.4.5, undoing the accidental 2.0.0 bumps from release PR #2602.
- **Why:** Manual Lerna intervention for `@endo/marshal` accidentally pushed the two coupled packages into 2.0; this restores intended versioning before the next breaking release.
- **Themes:** release, patterns, pass-style, changeset
- **Status:** merged

## Description

In https://github.com/endojs/endo/pull/2602, we inadvertently bumped the major versions for patterns and pass-style (while manually intervening in Lerna’s release process to avoid a major version bump for marshal)

In this change, we retroactively resume the 1.x train for these two packages.
