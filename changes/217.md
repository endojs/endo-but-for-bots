## Summary

- **What:** Aligns `@endo/ses`'s `package.json` so the package imports cleanly under CommonJS `require('ses')`, the `esm` shim (`node -r esm`), and Node.js native ESM, all under the same `'ses'` specifier; adds a regression test covering all three loaders.
- **Why:** Fixes #214; UMD use is preserved for the browser predicate.
- **Themes:** ses-lockdown, ecosystem-compat, tests
- **Status:** merged

## Description

This aligns ses/package.json such that SES can be imported with a CommonJS
loader, with the `esm` package using `node -r esm`, as well as Node.js ESM
support, all using the same "ses" name.

node main.js

    const { lockdown } = require('ses');

node main.mjs and node -r esm main.js

    import { lockdown } from 'ses';

This change includes a regression test that verifies each of these cases.

Fixes #214
