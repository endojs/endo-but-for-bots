## Summary
- add a new Endo `websocket` netlayer (`packages/ocapn/src/netlayers/websocket.js`) using framed websocket message transport via `ws`
- implement Spritely-compatible websocket designator authentication:
  - locator format uses `transport=websocket` with `hints.url`
  - designator is base32-encoded Ed25519 public key
  - connection challenge/response uses `init:peer-auth` and signed `desc:sig-envelope`
- switch goblin-chat interop host/client path from `tcp-testing-only` to websocket:
  - host now registers `makeWebSocketNetLayer`
  - Guile interop client now imports and uses Spritely's existing `(goblins ocapn netlayer websocket)`
- update Guile interop workflow/docs to reflect websocket transport
- add focused websocket netlayer tests for successful session establishment and auth rejection
- apply repository prettier formatting updates touched by `prettier --write`
- remove TCP-fragment buffering paths in the OCapN client:
  - remove `pendingHandshakeBytes` buffering in `client/index.js`
  - remove incomplete-syrup buffering in `client/handshake.js` and `client/ocapn.js`
  - remove fragmentation-specific tests in `test/client.test.js`
  - behavior now requires messages to be properly framed by transport
- fix Guile interop runtime imports by adding:
  - `(goblins utils hashmap)` for `hashmap-ref`
  - `(ice-9 iconv)` for `string->bytevector`

## Testing
- `yarn prettier --write .github packages`
- `yarn lint` (in `packages/ocapn`)
- `yarn test test/netlayer-websocket.test.js` (in `packages/ocapn`)
- `yarn test test/client.test.js` (in `packages/ocapn`)
- smoke check: `timeout 5 node ./packages/ocapn/test/goblin-chat/index.js interop-room` (verifies websocket peer/sturdyref URI output)

## Notes
- no fallback framing hacks are needed on websocket because message framing is provided by the transport
- sturdyref URI for the interop chatroom now carries `swiss` in query hints while preserving websocket peer designator identity
- after this update, TCP paths no longer attempt to reassemble fragmented syrup payloads; transports are expected to deliver complete framed syrup messages
