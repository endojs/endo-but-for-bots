## Summary

- **What:** Demote `@fast-check/ava` from a runtime to a dev dependency in `@endo/pass-style` by replacing direct `fc` imports in `tools.js` with a `makeArbitraries(fc)` factory.
- **Why:** Stop forcing `fast-check` into production dependency closures (fixes #1741); treated as non-breaking since no known external consumer imports the arbitraries.
- **Themes:** pass-style, tests, ecosystem-compat
- **Status:** merged

## Description

Fixes #1741

> [!CAUTION]
> While technically a breaking change, it is pragmatically not marked as such because we are not aware of anything outside of Endo that imports a fast-check arbitrary.

## Description

Rather than importing `fc` directly to export arbitraries, @endo/pass-style/tools.js now returns them from an exported `makeArbitraries` function that requires `fc` as an argument.
