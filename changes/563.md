## Description

Fixes #562 by renaming all test files and ava test file patterns to match the prevailing convention from Agoric SDK. This is a fully mechanical change.

This is an approximate reenactment:

```sh
find . -name '*.test.js' | grep -v 'node_modules' > list1
perl -pe 's/([^\/]+)\.test\.js/test-\1.js/' list1 > list2
paste list1 list2 | tr '\t' ' ' > list3
sed 's/^/git mv /' list3 | bash
find . -name package.json | xargs sed -i.bak 's/\*\.test\.js/test-*.js/'
rm list*
```
