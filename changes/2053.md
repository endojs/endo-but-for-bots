## Summary

- **What:** Moves shared helpers out of `test/test-*.js` files in `@endo/marshal` and `@endo/exo` into adjacent non-test `test/*.js` modules so ava no longer double-runs the exporting test files.
- **Why:** Follows the convention dckc raised in #2008 — `test-*.js` files should not export.

## Description

At https://github.com/endojs/endo/pull/2008#discussion_r1470460271 @dckc explained why `test/test-*.js` files should not export things. Currently, we have a few of those. This PR reforms those, moving shared stuff into separate `test/*.js` files that are not `test-*` files, and exporting from there.

### Testing Considerations
The whole point. By exporting from one `test-*.js` file and importing into another, ava would run sometimes run the exporting test twice, or when it did not need to.
