## Summary

- **What:** Moves the new-package skeleton into `packages/skel` and replaces `scripts/repackage.sh` with `scripts/create-package.sh`; the skeleton is now an ordinary workspace member tracked by Lerna.
- **Themes:** tooling, chore
- **Status:** merged

## Description

This moves the bulk of the project skeleton into `packages/skel`. The script `scripts/create-package.sh` takes over for the old `scripts/repackage.sh`. It loses the ability to update an existing package in-place (which has always been dubious) and instead allows the skeleton to more closely resemble an ordinary package, and allows `lerna` to keep the workspace dependencies of the skeleton up-to-date.
