## Summary

- **What:** Extends `@endo/compartment-mapper` `parseArchive` to compute and return an archive's SHA-512 when `computeSha512` is supplied (previously it could only validate `expectedSha512`).
- **Why:** Refs agoric-sdk #3859 — callers need to obtain the hash, not just verify a known one.
- **Themes:** compartment-mapper, security
- **Status:** merged

## Description

Refs: https://github.com/agoric/agoric-sdk/issues/3859

The compartment mapper will now compute and return the hash for an arbitrary archive when given a `computeSha512` option. Previously, parseArchive could only be used to validate the `expectedSha512`.
