## Summary

- **What:** Adds text and bytes asset module types to `@endo/compartment-mapper` (analogous to JSON modules), letting bundles ship and import binary or text assets without `fs`/`fetch` powers.
- **Why:** Replace the common `import.meta.url` + `fs`/`fetch` workaround with a primitive that survives bundling and archiving.
- **Themes:** compartment-mapper, bundle-source
- **Status:** merged

## Description

Motivated only to provide an Endo alternative to needing hacks like the use of `import.meta.url` in combination with `fs` or `fetch` powers that cannot be decoupled cleanly for bundling or archiving applications, this change introduces the notion of binary and text asset modules, which behave spiritually in much the same way as `json` type modules.
