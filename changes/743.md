## Summary

- **What:** `@endo/compartment-mapper` switches the on-disk archive format from Syrup to JSON and tightens module-language tags as an escape hatch.
- **Why:** Cross-language Syrup dictionary representation is not yet stable, so it isn't safe to commit to Syrup in the Endo archive format.
- **Themes:** compartment-mapper, bundle-source
- **Status:** merged

## Description

Due to a discrepancy between language representations for Syrup dictionaries, our Syrup implementation is not yet stable and isn’t yet suitable for use in the Endo archive file format. I’ve left an escape hatch in the form of increasing the specificity of the module language tags.

Fixes #743
