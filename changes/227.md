## Summary

- **What:** Adds missing override-enablements for `AsyncFunction.prototype` and `AsyncGeneratorFunction.prototype` (`constructor`, `name`, `toString`) to the SES enablements table (fixes #226).
- **Why:** Without these enablements, common attempts to override standard `name`/`toString` on async (generator) functions throw under hardened intrinsics.
- **Themes:** ses-lockdown
- **Status:** merged

## Description

Fixes #226 

I didn't include these two. Looks like there were also tests validating that they are override-able, wouldn't want to lose them either 
https://github.com/Agoric/SES/commit/d695dfbcf3b37a31d4ae0ab3f9ae7a754f02fd26
```
   AsyncFunction: {
      prototype: {
        constructor: t,
        name: t,
        toString: t,
      },
    },

    AsyncGeneratorFunction: {
      prototype: {
        constructor: t,
        name: t,
        toString: t,
      },
    },
```
