This is an initial version of the `@endo/hash-bundle` package that can generate “version strings” for all three kinds of Endo bundle. The `lite.js` module has no powerful built-in module dependencies.

### @kriskowal (MEMBER) — 2022-03-01T07:00:04Z

I’ve changed `hash-bundle` to `check-bundle`, and the hash is expressed with an `endoZipBase64Sha512` property on the bundle itself. The integrity checker rejects if the bundle is internally inconsistent. I changed `bundleSource` to generate the expected hash property too, which required a small enhancement to compartment-mapper. Commits are individually reviewable.

I discovered, late, that the reason Windows tests were failing was not because I had failed to normalize the inputs, but because `recast` was generating platform-appropriate line-endings. I rebased atop @michaelfig’s upcoming https://github.com/endojs/endo/pull/1096 which reverts recast in favor of babel’s own codegen and the problem went away.
