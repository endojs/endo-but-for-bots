## Summary

- **What:** Adds `@endo/cjs-module-analyzer`, forked from `cjs-module-lexer`, that statically extracts `imports`, `exports`, and `export * from` re-exports from CommonJS sources.
- **Why:** Part two of #501/#655 — Endo needs import-graph analysis that Node's upstream lexer doesn't provide.
- **Themes:** compartment-mapper, ecosystem-compat
- **Status:** merged

## Description

In preparation for adding CommonJS support back to Endo, this adds a package forked off https://github.com/guybedford/cjs-module-lexer that allows us to statically analyze `imports`, `exports`, and `reexports` (`export * from _`).

The fork is required because import graph analysis is not required for Node.js upstream, since its module loader is still synchronous. I’ve discussed with @guybedford the possibility of collaboration, and it seems the best we can do for now is attempt to make the fork as similar to the original as possible to make tracking easy. Changes should not be frequent.

Part two of #501 #655
