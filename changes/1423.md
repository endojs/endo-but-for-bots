## Pull Request Overview

This pull request implements an event-based encoding API based on Data-E, introducing a new builder pattern architecture for marshal encoding/decoding operations. The change adds builder abstractions for different encoding formats (smallcaps, Justin expressions, and JS subgraphs) that follow a common interface pattern.

Key changes:
- Introduces a builder/recognizer pattern for different encoding formats
- Adds smallcaps, Justin, and subgraph builders with unified interfaces
- Extracts common marshal test functionality into shared utilities
- Removes TypeScript triple-slash reference comments from source files
