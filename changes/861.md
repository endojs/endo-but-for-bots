## Summary

- **What:** `@endo/compartment-mapper` now resolves a package importing its own name (reflexive `import 'self/...'`), matching Node ESM behavior.
- **Why:** Unblocks Agoric SDK PR #3273 where tests need to import the package they live in via its public name.
- **Themes:** compartment-mapper, ecosystem-compat

## Description

In Node.js ESM, a package may import its own name. This is particularly
useful for creating tests and testing examples of usage from a
third-party perspective, and is necessary for feature parity.

Blocks https://github.com/Agoric/agoric-sdk/pull/3273
