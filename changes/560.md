## Description

This change subsumes the `@agoric/base64` package from the Agoric SDK into the SES shim repository as `@endo/base64`.

This is a move to practice migrating code while preserving its history using `git subtree`. The construction of this branch consisted of:

```js
agoric-sdk$ git subtree split --prefix packages/base64 HEAD --branch split-base64
agoric-sdk$ cd ../ses-shim
ses-shim$ git remote add agoric-sdk ../agoric-sdk
ses-shim$ git fetch agoric-sdk --no-tags
ses-shim$ git subtree add --prefix packages/base64 agoric-sdk/split-base64
```

Then, updates for the repository package.json workspaces, yarn.lock, and renaming the package to `@endo/base64`.

The significance of the rename is that it will allow us to establish legitimacy of our ownership of the `endo` organization on `npm` before it’s appropriated legitimately by their name-squatting policy.
