## Description

This change, initiated by @Jack-Works, gets all of the Endo tests passing on Windows and introduces Windows CI.

This largely consists of rigorous use of `fileURLToPath` and `filePathToURL` from Node.js’s `url` module, and threading the `url` module into the file powers used by Endo’s compartment mapper. This has been done without a breaking change, but deprecation and replacement of the `@endo/compartment-mapper/node-powers.js` functions.

Shell quoting on Windows is very different than Linux. For example, CMD.EXE does not support single quotes and *does* expand `*` in double quotes. This interferes with the glob patterns we passed to eslint. Thankfully, just removing the globs was easier and more suitable than arriving at cross-platform escapes.

In the course of making this change, I anticipated that it would be necessary to disable the Endo symlink test. Toward that end, I made some forward progress on factoring out a scaffold for compartment mapper tests. This did not turn out to be necessary, but is progress regardless, since we need the scaffold to greatly expand the covered cases.

Commits are individually reviewable.
