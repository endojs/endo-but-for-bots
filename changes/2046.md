## Summary

- **What:** Lets `provideHost`/`provideGuest` (and `mkhost`/`mkguest` in `@endo/cli`) accept `introducedNames` so the creator can pre-populate the new host/guest's pet store; also exposes `petStore` on the host/guest internal facet.
- **Why:** Allows callers creating a guest/host to seed it with petnames at creation time rather than after-the-fact wiring.
- **Themes:** daemon, cli
- **Status:** merged

## Description

Allows host or guest to be created with petnames populated by creator
