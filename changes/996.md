- **What:** `@endo/marshal`'s `unserialize` now asserts that every object it produces is a passable, rejecting thenables before they can re-enter the system.
- **Why:** Fixes Agoric SDK #4337 and #4302 — thenables sneaking through unserialize broke object-capability invariants.
