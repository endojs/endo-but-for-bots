## Summary

- **What:** Breaking change to the SES module preamble: precompiled records from `static-module-record` now pass entries arrays instead of a `Map`, so user code can name `Map` in module scope without shadowing.
- **Why:** Fixes #823 — user modules that declared `const Map = ...` clashed with the preamble's reliance on `Map`.
- **Themes:** ses-lockdown, compartments, compartment-mapper
- **Status:** merged

## Description

Fixes #823

This is a breaking change because it alters the calling convention between
precompiled module records and the SES module initializer.

- fix(static-module-record)!: Remove reliance on Map in scope of preamble
- fix(ses)!: Adjust preamble for module instances to expect entries instead of a Map
- fix(compartment-mapper): Adjust bundle calling convention for preamble
