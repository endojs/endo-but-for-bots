## Summary

- **What:** Lets `@endo/daemon`/`@endo/cli` `make` and `store` commands target deeper pet-name paths like `dir.x` so caplets and stored values can live in nested name directories.
- **Themes:** daemon, cli, familiar
- **Status:** merged

## Description

Enables caplets to be made and values to be stored at deeper pet name paths.

```
endo make x.js -n dir.x
endo store --json 42 -n dir.forty-two
endo store --text-stdin --name dir.greeting < <(echo hi)
```
