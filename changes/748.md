## Summary

- **What:** `@endo/base64` and `@endo/ses-ava` add `package.json` to their `exports` so Node ESM can import the descriptor.
- **Why:** Svelte tooling needs each package's metadata, and Node ESM hides anything not listed in `exports`.
- **Themes:** ecosystem-compat, chore
- **Status:** merged

## Description

Svelte tooling needs access to each package’s metadata. Node.js ESM now requires public access to modules in a package to be expressed in an `exports` property (if present). This change lines up `ses-ava` and `base64`, which lagged behind the current package skeleton.
