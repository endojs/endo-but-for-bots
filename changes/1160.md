## Summary

- **What:** Adds a `bundle-source` CLI tool to `@endo/bundle-source` that writes bundle output and meta JSON files into a cache directory and rebuilds only when source mtimes change.
- **Why:** Refs agoric-sdk #3609 — bundling is slow and benefits from a content/mtime-based cache for repeated runs.
- **Themes:** bundle-source, cli, performance
- **Status:** merged
