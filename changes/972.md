## Summary

- **What:** Adds `mapReader`/`mapWriter` to `@endo/stream` and retracts the now-redundant `@endo/stream-json` package, since JSON encoding becomes a one-line `mapReader`.
- **Themes:** captp, marshal
- **Status:** merged

## Description

This change introduces `mapReader` and `mapWriter`, which obviate the need for the stream-json package entirely. This became clear when I realized that I ought to factor `stream-text` out of `stream-json` and the resulting packages with more focused scope were nearly identical. Consequently this change includes a second commit that just removes the unpublished `@endo/stream-json` package.
