## Summary

- **What:** Replaces multi-occurrence `--as foo --as bar` syntax with dot-delimited `--as foo.bar` paths across all `@endo/cli` commands.
- **Why:** Unifies path syntax with the petname-path work in #2034 / #2022.
- **Themes:** cli
- **Status:** merged

## Description

The CLI `--as` option previously supported paths like this:
```
endo list --as foo --as bar
```

This does away with the ability to specify the option multiple times, and replaces it with dot-delimited path support:
```
endo list --as foo.bar
```

This works for all commands.
