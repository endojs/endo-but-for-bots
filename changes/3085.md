## Pull request overview

This PR moves the async_hooks patch from the default Node.js load path to a dedicated opt-in entrypoint to fix Node.js 24 compatibility issues. The async_hooks patch was originally added to support debuggers in lockdown mode, but it breaks in Node.js 24 and may no longer be necessary in newer Node.js versions.

**Changes:**
- Removed automatic application of async_hooks patch on Node.js by deleting conditional exports
- Created new `@endo/init/debug-async-hooks.js` entrypoint for users who need the patch
- Updated tests to skip on Node.js 24+ where the patch is broken
