## Summary

- **What:** Makes every `@endo/daemon` formula number unique, derived either from a per-instance "seed" (persisted until next `purge`) or random; some are deliberately derived from a parent (e.g. pet-store-from-inspector) so factories can name their children.
- **Why:** The earlier zero-id512 placeholders for well-known formulas (#2058/#2062-#2066) collided; this gives them stable but distinct identities.
- **Themes:** daemon, security
- **Status:** merged

## Description

Ensures that all formula numbers unique by either deriving them from a root "seed" value or randomly generating them. The seed value exists until the next `purge`.

We in some cases rely on formula number derivation paths to reference other values. For example, the pet store number is derived from the inspector number, so that the inspector factory function can easily reference the pet store.
