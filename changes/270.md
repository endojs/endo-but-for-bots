## Summary

- **What:** Lets consumers silence the SES `SecurityWarning` about missing `harden` by setting `globalThis.harden = false`, and clarifies the warning text.
- **Why:** Tests and apps that have not yet wired in `@agoric/harden` need a way to suppress the noisy warning.
- **Themes:** ses-lockdown, errors
- **Status:** merged

## Description

The `SecurityWarning` should be able to be explicitly silenced.  One way to do this is:

`my-test.js`:

```js
import './initialize-ses.js';
import harden from '@agoric/harden';

... test code
```

`initialize-ses.js`:

```js
// Tell that we don't have harden yet, but don't want to warn.
globalThis.harden = false;
```
</details>

Also, update the text of the `SecurityWarning` to describe what the issue is.
