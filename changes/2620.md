## Summary

- **What:** Fix `@endo/compartment-mapper` CJS parsers to invoke the wrapper functor with `module.exports` as `this` so top-level `this === module.exports === exports` matches Node CommonJS semantics.
- **Why:** CJS compatibility (some packages rely on `this` at module scope).
- **Themes:** compartment-mapper, ecosystem-compat
- **Status:** merged

## Description

For CJS compat, the top-level `this` must be equal to `module.exports` (which must be equal to `exports`).

This implementation changes the CJS parsers to call the wrapper `functor` using the context of `module.exports`.
