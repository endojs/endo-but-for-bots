## Summary

- **What:** Removes `readAny`/`writeAny` from `@endo/ocapn`'s reader/writer and codec, and moves generic-syrup serde into a new `js-representation` module used only by tests.
- **Why:** Forces a clean separation between OCapN Passables and generic syrup values so OCapN messages can't accidentally carry non-Passable shapes.
- **Themes:** ocapn, marshal, pass-style
- **Status:** merged

## Description

Serde of structures (list, sets, dictionaries) implies an understanding of the values they could contain.
Generic syrup values and OCapN Passables can contain a different set of values.

In order to clearly delineate generic syrup values and OCapN values, all reading of structures has been moved out of the primary modules of reader/writer and codec. a new module `js-representation` is used for serde of generic syrup values, as used in tests.

This makes it easy to ensure OCapN values will never accidentally contain generic syrup values.
