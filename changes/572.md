## Description

Fixes https://github.com/Agoric/agoric-sdk/issues/2326#issuecomment-773020389 by recognizing ellipses as suggested there, so

```
Object.bootstrap (v1/.../SwingSet/test/vat-admin/terminate/bootstrap-speak-to-dead.js:40:59)
```
gets shortened to
```
Object.bootstrap (SwingSet/test/vat-admin/terminate/bootstrap-speak-to-dead.js:40:59)
```

Refactor the filtering and shortening of concise stack traces to be more data driven, so that it can eventually be made user configurable, and so the testing and filtering rules can be unit tested.

Unit test them.
