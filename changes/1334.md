## Summary

- **What:** Introduces the `Fail` tagged-template helper in `@endo/errors` so `cond || Fail\`...\`` replaces `cond || assert.fail(X\`...\`)` across 25 source files.
- **Why:** More compact and readable than the wrapped `assert.fail(X\`...\`)` form while keeping the same fast-path performance.
- **Themes:** errors, performance
- **Status:** merged

## Description

See https://github.com/Agoric/agoric-sdk/pull/6482

Prior to this PR, our new assertion style let to many statements of the form
```js
condition || assert.fail(X`...`);
```
with this PR, we can now write
```js
condition || Fail`...`;
```
which is more compact and more readable.
