## Description

Applies review feedback from PR #3194:

- Reverts the `<un-decodable>` fallback in handshake decode error handling and restores direct `decodeSyrup(...)` behavior in `packages/ocapn/src/client/handshake.js`.

- Removes the prospective documentation file `packages/ocapn/src/netlayers/tor-setup.md`.
