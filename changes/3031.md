> [!NOTE]
> Modernizes OCapN messaging and lifecycle semantics with clearer promise handling and accurate refcounting.
> 
> - Refactor client/ref-kit to use the HandledPromise-returned promise as the registered `answer`, add explicit `apply*SendOnly` pathways, and pipeline using internal vs external promises; `fulfill/break` now use send-only
> - Introduce precise refcount APIs: `recordSentSlot`/`recordReceivedSlot` and per-message counting; remove implicit increments from lookups; adjust tables to drop/GC correctly and reject pending settlers on `destroy(reason)`
> - Propagate disconnect reasons: `ocapn.abort(reason: Error)` tears down connection and rejects all pending remote answers; local answers are preserved on the responder
> - Codecs/descriptors: wrap errors with `cause`, `DescAnswer` reads via `getLocalAnswerValue`
> - CI/test: update Python test-suite ref, capture server logs; expose GC for test server and add GC utilities; add comprehensive unit/integration tests for pipelining, GC (export/answer), E vs E.sendOnly, disconnect behavior
