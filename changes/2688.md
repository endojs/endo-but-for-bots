## Description

Since the last work on this immutable-arraybuffer shim, at the tc39 plenary we decided that 
- `transferToImmutable` should take an optional `newLength` parameter, to stay parallel to the other `transfer*` methods.
- The `sliceToImmutable` method should be added.

The spec at https://github.com/tc39/proposal-immutable-arraybuffer and the Moddable XS implementation both already reflect these changes. This PR brings this shim up to date with those changes, closing https://github.com/tc39/proposal-immutable-arraybuffer/issues/26
