## Summary

- **What:** Adds a test asserting `@endo/ses` lockdown completes under a no-unsafe-eval CSP, subsuming the fix in #1333.
- **Why:** CSP environments (browser extensions) disable evaluators entirely; lockdown should still complete and not produce excessive warnings.
- **Themes:** ses-lockdown, security, ecosystem-compat, tests
- **Status:** open / draft

## Description

This change adds a test that verifies that Lockdown runs to completion even in the absence of a usable evaluator.
