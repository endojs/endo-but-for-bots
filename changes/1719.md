## Description

There was some problem with `magic-string` dependency in Rollup, which was circumvented by making a patched copy of Rollup at https://github.com/endojs/endo/tree/rollup-2.7.1-patch-1 and having `bundle-source` depend on that. That caused a problem for PNPM installs (#1716 ).

This PR updates Rollup to the latest non-breaking version, which is confirmed to have the version of magic-string that the patch file says is sufficient.

It also bumps `yarn` which had printed a warning while I was doing the other change.
