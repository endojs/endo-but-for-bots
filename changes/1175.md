## Summary

- **What:** Stabilizes `@endo/compartment-mapper` archive hashes by only assigning disambiguating sequence numbers when package name+version collide, choosing the shortest dependency path as the canonical name.
- **Themes:** compartment-mapper, bundle-source
- **Status:** merged

## Description

Before this change, the compartment map would contain a sequence number on every compartment to disambiguate compartments produced by packages with the same name and version but different physical locations.

After this change, compartments only have a disambiguating sequence number if there is a name collision, and only for each package after the first. The order in which colliding compartments appear is based on the lexical order of their respective dependency name paths, favoring the shortest of all the dependency paths that arrive at the same physical location, or as @kumavis calls it, the package’s ’a’a.
