## Summary

- **What:** Folds the `lockdown-shim` and `compartment-shim` packages and their internal deps into the single `@endo/ses` package, gathering licenses there and normalizing source filenames to kebab-case.
- **Why:** Gives the project flexibility to reorganize SES internals without juggling multiple subpackages.
- **Themes:** ses-lockdown, compartments, chore
- **Status:** merged

## Description

This change subsumes lockdown-shim, compartment-shim and their internal
dependencies to grant us more flexibility to adjust organization going
forward.

- Source file names generally formed from prior package names.
  I took the liberty to normalize the file name case convention to
  kebab-case.
  This includes tests and test262s.
- All licenses are gathered in the SES package.
- Some readmes are converted to code docs.
