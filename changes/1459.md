## Summary

- **What:** Migrates the exo support (heap-only `Exo` objects and classes, and the implementation machinery shared with `@agoric/vat-data`'s virtual/durable exos) from `@agoric/store` into a new `@endo/exo` package depending on `@endo/patterns`; renames `*HeapExo*` to `*Exo*`.
- **Themes:** exo, patterns
- **Status:** merged

## Description

Migrated the exo support from the `@agoric/store` package. Changed to depend on `@endo/patterns` which was previously migrated from `@agoric/store`.

This directly supports only the heap implementations of exo objects and exo classes, but also provides the common implementation machinery used by `@agoric/vat-data` (via `@agoric/swing-set`) to implement virtual and durable exos. See doc/exo-taxonomy.md in this PR for these relationships.
