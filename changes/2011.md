## Summary

- **What:** Renames the `@endo/cli` `--UNSAFE` flag and corresponding `@endo/daemon` internals (e.g. `import-unsafe`) to `--UNCONFINED`/`unconfined` (breaking, requires `endo purge --force`).

- **Themes:** cli, daemon, security

## Description

Renames the `UNSAFE` flag to `UNCONFINED`, which is more specific. Also renames internals using "unsafe" (like `import-unsafe`) to use "unconfined" instead.

Will require an `endo purge -f`.
