## Summary

- **What:** Adds `name` to the moderate-`overrideTaming` list for every error constructor in SES so Node 14's internal error-creation path doesn't trip the override mistake.
- **Why:** Anomalous Node behavior (tracked in #868) writes to `error.name`, which without the override produced "TypeError: Cannot assign to read only property 'name'".
