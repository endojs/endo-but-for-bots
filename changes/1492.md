## Summary

- **What:** External proposal adding `.then` detection to `@endo/eventual-send` `pendingHandler` so CapTP can listen-on-interest, modeled after Spritely Goblins; rejected because Endo's `Promise.resolve(p) === p` checks would trigger the new "interest" handler.
- **Themes:** eventual-send, captp, ocapn
- **Status:** closed-unmerged

## Description

This is usefull for detecting intrest in what a remote promise resolves to in CapTP of Spritely Goblins, for example. In that case an op:listen or such can be sent over the connection and, crucially, skip that iff no interest is shown and the handled promise is only used as an target or an argument of an eventual send.

See [this ocapn issue](https://github.com/ocapn/ocapn/issues/15) for more details.
